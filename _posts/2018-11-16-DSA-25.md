Chào các bạn, mở rộng DP lên **2 chiều** — cần thiết khi state phụ thuộc hai tham số (ví dụ: hai string, grid position).

## 1. 2D DP Table:

`dp[i][j]` = optimal value cho subproblem với tham số `(i, j)`.

Fill thường theo thứ tự row-by-row hoặc diagonal.

## 2. Longest Common Subsequence (LCS):

{% include dsa25-dp2d-demo.html %}

Transition:
+ Nếu `s1[i-1] == s2[j-1]`: `dp[i][j] = dp[i-1][j-1] + 1`
+ Else: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

**Time**: O(m × n), **Space**: O(m × n), có thể optimize O(min(m,n))

## 3. Grid DP:

+ **Unique Paths**: `dp[i][j] = dp[i-1][j] + dp[i][j-1]`
+ **Minimum Path Sum**: `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`
+ **Edit Distance**: insert, delete, replace operations

---

## Common Mistakes: 2D DP

- **Index off-by-one**: dp table thường size (m+1)×(n+1) với row 0/col 0 = base case.
- **Iteration order**: Phụ thuộc direction — path sum fill top-left to bottom-right.
- **Space**: Rolling array giảm 2D → 1D khi chỉ cần previous row.
