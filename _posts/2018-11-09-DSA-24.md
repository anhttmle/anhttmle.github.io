Chào các bạn, **Dynamic Programming** (**DP**) giải quyết bài toán có **overlapping subproblems** và **optimal substructure** bằng cách lưu kết quả thay vì tính lại.

## 1. Hai điều kiện DP:

+ **Optimal substructure**: Optimal solution chứa optimal solutions của subproblems
+ **Overlapping subproblems**: Cùng subproblem được giải nhiều lần (khác Divide & Conquer)

## 2. Climbing Stairs (1D DP):

\\[
dp[i] = dp[i-1] + dp[i-2]
\\]

## 3. Top-down vs Bottom-up:

+ **Top-down (memoization)**: Recursion + cache
+ **Bottom-up (tabulation)**: Fill table từ base case lên

## 4. Classic 1D DP:

+ **House Robber**: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
+ **Coin Change**: min coins for amount
+ **Longest Increasing Subsequence**: O(n²) hoặc O(n log n) với binary search

---

## Common Mistakes: 1D DP

- **Wrong state definition**: Xác định `dp[i]` đại diện gì trước khi viết transition.
- **Missing base case**: dp[0], dp[1] phải init đúng.
- **Space optimization**: Nhiều 1D DP chỉ cần 2-3 biến thay vì full array.
