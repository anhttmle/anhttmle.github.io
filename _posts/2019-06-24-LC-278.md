*Bài này áp dụng **Binary Search on monotonic space** từ [DSA Understanding – Part 16](/dsafundamental/2018/09/14/DSA-16.html).*

## 1. Đề bài đầy đủ

Có `n` version `1..n`. Có API `isBadVersion(version)` trả `true` nếu version đó **bad**. Sau version bad đầu tiên, **mọi version sau đều bad**. Tìm **bad đầu tiên**, tối thiểu số lần gọi API.

## 2. Ví dụ minh hoạ

| n | bad (ẩn) | Output |
|---|----------|--------|
| 5 | 4 | 4 |
| 1 | 1 | 1 |

## 3. Nhận diện pattern

+ Không search giá trị trong array mà search **answer** trên `[1, n]`
+ Monotonic: `false … false true … true`
+ Tìm **first true** = lower bound trên predicate

## 4. Hướng tiếp cận từng bước

1. `lo = 1`, `hi = n`
2. `while lo < hi`: `mid = lo + (hi-lo)//2`
3. Nếu `isBadVersion(mid)` → `hi = mid` (có thể là đáp án)
4. Ngược lại → `lo = mid + 1`
5. Trả `lo`

## 5. Code Python

```python
def firstBadVersion(n: int) -> int:
    lo, hi = 1, n
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if isBadVersion(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo
```

*(Giả sử `isBadVersion` do LeetCode cung cấp.)*

## 6. Trace n=5, bad=4

| lo | hi | mid | isBad(mid) |
|----|----|-----|------------|
| 1 | 5 | 3 | F → lo=4 |
| 4 | 5 | 4 | T → hi=4 |

→ **4**

## 7. Phân tích độ phức tạp

+ **Time O(log n)** API calls
+ **Space O(1)**
