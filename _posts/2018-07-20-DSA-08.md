Chào các bạn, tiếp nối Two Pointer opposite direction, hôm nay ta xem **Same Direction** — hai con trỏ cùng hướng, trong đó hay gặp nhất là **Fast & Slow Pointers** (tortoise and hare).

## 1. Same Direction:

Cả hai pointer đều di chuyển từ trái sang phải (hoặc cùng hướng), nhưng **tốc độ khác nhau** hoặc **vai trò khác nhau**.

+ **Fast/Slow**: slow += 1, fast += 2 mỗi bước
+ **Read/Write**: read duyệt, write ghi kết quả (remove duplicates in-place)

## 3. Ứng dụng:

+ **Linked List Cycle** (LeetCode #141): O(n) time, O(1) space
+ **Find Middle Node**: khi fast tới tail, slow ở giữa
+ **Remove Duplicates Sorted Array**: write pointer chỉ tăng khi gặp giá trị mới
+ **Move Zeroes**: write pointer gom non-zero về trước

---

## Common Mistakes: Fast & Slow Pointer

- **Fast null check**: Luôn check `fast && fast.next` trước `fast = fast.next.next`.
- **Off-by-one middle**: Với list chẵn node, middle có thể là node thứ n/2 hoặc n/2+1 — thống nhất đề bài.
- **Dùng trên array thay vì linked list**: Cycle detection chỉ meaningful trên linked list có cycle.
