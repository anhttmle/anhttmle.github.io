Chào các bạn, mở rộng prefix sum lên ma trận 2D — công cụ mạnh cho bài toán trên grid và submatrix.

## 1. 2D Prefix Sum:

\\[
P[i][j] = \sum_{r=0}^{i-1}\sum_{c=0}^{j-1} matrix[r][c]
\\]

Công thức build (inclusion-exclusion):

\\[
P[i][j] = matrix[i-1][j-1] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]
\\]

## 2. Range Sum Query trên submatrix:

Tổng vùng `(r1,c1)` → `(r2,c2)`:

\\[
\text{sum} = P[r2+1][c2+1] - P[r1][c2+1] - P[r2+1][c1] + P[r1][c1]
\\]

## 3. Subarray Sum problems:

+ **Maximum Subarray** (Kadane's): O(n) không cần prefix
+ **Submatrix Sum Query**: O(1) query sau O(mn) preprocess
+ **Count Square Submatrices**: kết hợp DP + prefix

---

## Common Mistakes: 2D Prefix Sum

- **1-indexed prefix**: P có size (m+1)×(n+1), row 0 và col 0 toàn 0.
- **Inclusion-exclusion sign**: Trừ P[r1][c2+1] và P[r2+1][c1], cộng lại P[r1][c1].
- **Nhầm với integral image**: Công thức giống nhau nhưng index convention khác nhau giữa các nguồn.
