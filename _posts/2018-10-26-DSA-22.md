Chào các bạn, hôm nay ta tìm hiểu **Heap** — cấu trúc dữ liệu dùng cho Priority Queue và Heap Sort.

## 1. Heap Properties:

**Binary Heap** là complete binary tree thỏa **heap property**:

+ **Min Heap**: parent ≤ children → root là minimum
+ **Max Heap**: parent ≥ children → root là maximum

Lưu trữ bằng **array**: node tại index `i` có children tại `2i+1` và `2i+2`.

## 2. Push (Insert):

1. Thêm phần tử cuối array
2. **Bubble up** (sift up): swap với parent nếu vi phạm heap property

**Time**: O(log n)

## 3. Pop (Extract Min/Max):

1. Lưu root (min/max)
2. Move phần tử cuối lên root, xóa cuối
3. **Bubble down** (sift down): swap với child nhỏ hơn (min heap)

**Time**: O(log n)

## 4. Use Cases:

+ **Priority Queue**: Dijkstra, task scheduling
+ **Heap Sort**: O(n log n), in-place
+ **Top K Elements**: min heap size k
+ **Merge K Sorted Lists**

---

## Common Mistakes: Heap

- **Nhầm min/max heap**: Top K largest dùng min heap size k; Top K smallest dùng max heap.
- **Index formula**: Parent of i = `(i-1)//2`, không phải `i//2`.
- **Heap vs BST**: Heap chỉ guarantee root min/max, không sorted toàn bộ.
