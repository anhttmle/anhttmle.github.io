*Bài này áp dụng **BST** từ [DSA Understanding – Part 19](/dsafundamental/2018/10/05/DSA-19.html).*

## 1. Đề bài đầy đủ

Cho `root` của BST và số nguyên `val`. Trả về **subtree** có root.val == `val`, hoặc `null` nếu không tồn tại.

## 2. Ví dụ minh hoạ

```
        4
       / \
      2   7
     / \
    1   3
```
`val = 2` → subtree gốc 2 (có con 1, 3). `val = 5` → null.

## 3. Nhận diện pattern

+ BST property → mỗi bước loại một nhánh
+ Giống binary search nhưng trên cây: O(h)

## 4. Hướng tiếp cận từng bước

1. `node` null → null
2. `val == node.val` → return node
3. `val < node.val` → search left; else → search right

## 5. Code Python

```python
def searchBST(root: TreeNode | None, val: int) -> TreeNode | None:
    cur = root
    while cur:
        if val == cur.val:
            return cur
        if val < cur.val:
            cur = cur.left
        else:
            cur = cur.right
    return None
```

## 6. Trace val=2

| cur.val | Hành động |
|---------|-----------|
| 4 | 2 < 4 → left |
| 2 | **return cur** |

## 7. Phân tích độ phức tạp

+ **Time O(h)** — h = height; balanced O(log n)
+ **Space O(1)** iterative
