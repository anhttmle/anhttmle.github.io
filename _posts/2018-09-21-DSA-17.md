Chào các bạn, mở rộng binary search cho bài toán **tìm boundary** — lower bound, upper bound, search insert position.

## 1. Lower Bound:

Tìm **index nhỏ nhất** sao cho `arr[i] >= target`:

{% include dsa17-binary-search-range-demo.html %}

+ Nếu `arr[mid] >= target`: `ans = mid`, `hi = mid - 1` (tìm leftmost)
+ Nếu `arr[mid] < target`: `lo = mid + 1`

## 2. Upper Bound:

Tìm index nhỏ nhất sao cho `arr[i] > target` — tương tự nhưng điều kiện `arr[mid] > target`.

## 3. Ứng dụng:

+ **Search Insert Position** (LeetCode #35): lower bound
+ **Find First and Last Position**: lower + upper bound
+ **Count occurrences**: upper - lower
+ **Binary Search on Answer**: không search array mà search giá trị answer (min max, koko eating bananas)

---

## Common Mistakes: Binary Search on Range

- **Duplicate elements**: Standard binary search trả về any match; cần lower/upper bound cho first/last.
- **Empty result**: Target lớn hơn tất cả → lower bound = n.
- **Binary search on answer**: Verify function monotonic trước khi apply template.
