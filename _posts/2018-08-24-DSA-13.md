Chào các bạn, sau Two Pointer và Sorting, hôm nay ta tìm hiểu **Linked List** — cấu trúc dữ liệu thay thế array khi cần insert/delete linh hoạt.

## 1. Singly Linked List:

Mỗi **node** gồm `value` và `next` pointer trỏ tới node kế tiếp. Node cuối trỏ `null`.

{% include dsa13-linkedlist-demo.html %}

+ **Access by index**: O(n)
+ **Insert/Delete tại vị trí biết**: O(1)
+ **Search**: O(n)

## 2. Doubly Linked List:

Mỗi node có thêm `prev` pointer — duyệt ngược được, delete dễ hơn khi đã có node pointer.

+ **Space**: O(2n) pointers thay vì O(n)
+ **Insert/Delete**: O(1) với node reference

## 3. Array vs Linked List:

| | Array | Linked List |
|---|-------|-------------|
| Random access | O(1) | O(n) |
| Insert head | O(n) | O(1) |
| Cache locality | Tốt | Kém |
| Memory | Compact | Overhead pointers |

---

## Common Mistakes: Linked List

- **Losing reference to head**: Khi insert/delete, luôn giữ `head` pointer.
- **Null pointer**: Check `node != null` trước khi truy cập `node.next`.
- **Off-by-one với dummy node**: Dummy node giúp simplify insert/delete ở head.
