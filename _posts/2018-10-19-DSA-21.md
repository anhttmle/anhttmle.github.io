Chào các bạn, từ Tree traversal ta đã gặp recursion. Hôm nay ta formalize **Recursion** — kỹ thuật nền tảng cho Backtracking, DP, và Graph.

## 1. Recursion là gì?

Function gọi chính nó với input nhỏ hơn, cho đến **base case** dừng lại.

**Factorial**:
\\[
n! = n \times (n-1)!, \quad 0! = 1
\\]

**Fibonacci**:
\\[
fib(n) = fib(n-1) + fib(n-2), \quad fib(0)=0, fib(1)=1
\\]

## 2. Call Stack:

Mỗi recursive call push một **stack frame** lên call stack. Stack overflow khi recursion quá sâu.

+ **Time** (naive fib): O(2ⁿ) — overlapping subproblems
+ **Space**: O(n) stack depth

## 3. Memoization:

Cache kết quả subproblem đã tính → **O(n)** time, **O(n)** space.

> **Lưu ý**: Recursion = DFS mindset. Mọi recursive algorithm đều có thể viết iterative với explicit stack.

---

## Common Mistakes: Recursion

- **Thiếu base case**: Infinite recursion → stack overflow.
- **Không giảm problem size**: Mỗi call phải tiến về base case.
- **Naive Fibonacci**: O(2ⁿ) — dùng memoization hoặc DP tabulation.
