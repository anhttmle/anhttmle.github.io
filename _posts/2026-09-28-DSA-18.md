Chào các bạn, sau Linked List và Binary Search, ta bước vào **Tree** — cấu trúc phân cấp quan trọng bậc nhất trong DSA.

## 1. Binary Tree:

Mỗi node tối đa **2 children**: **left** và **right**. Node không có con gọi là **leaf**.

{% include dsa18-binary-tree-demo.html %}

**Thuật ngữ**:
+ **Root**: node gốc
+ **Height**: độ sâu max từ root tới leaf
+ **Depth**: khoảng cách từ root tới node
+ **Level**: tập node cùng depth

## 2. Tree vs Graph:

+ Tree: **connected**, **acyclic**, có đúng **n-1 edges** với n nodes
+ Graph: có thể có cycle, không nhất thiết có root

## 3. Full vs Complete vs Perfect:

+ **Full**: mỗi node có 0 hoặc 2 children
+ **Complete**: mọi level đầy trừ level cuối, fill từ trái
+ **Perfect**: mọi level đầy, 2^h - 1 nodes

---

## Common Mistakes: Binary Tree

- **Null node**: Luôn check `if not node: return` trong recursive traversal.
- **Nhầm height và depth**: Height tính từ node xuống leaf; depth tính từ root xuống node.
- **Single node tree**: Height = 0 hoặc 1 tùy convention — thống nhất đề bài.
