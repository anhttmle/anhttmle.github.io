*Bài này áp dụng **Adjacency List + BFS/DFS** từ [DSA Understanding – Part 27](/dsafundamental/2018/11/30/DSA-27.html).*

## 1. Đề bài đầy đủ

Cho `node` — reference tới node đầu của **undirected graph**. Mỗi node có `val` và list `neighbors`. Trả về **deep copy** của graph.

Node definition: `Node(val, neighbors=[])`

## 2. Ví dụ minh hoạ

**Input:** Adj list `[[2,4],[1,3],[2,4],[1,3]]` — 4 nodes, hình vuông.

**Output:** Copy mới cùng cấu trúc, không share reference với graph gốc.

## 3. Nhận diện pattern

+ Graph traversal (BFS/DFS) trên **adjacency list**
+ **Hash Map** `old_node → new_node` tránh clone trùng và giữ edges
+ Mỗi node gốc map đúng một node mới

## 4. Hướng tiếp cận từng bước

**BFS:**

1. Nếu `node is None` → return None
2. `cloned = {node: Node(node.val)}`, queue `[node]`
3. While queue:
   - Dequeue `cur`
   - Với mỗi `neighbor` của `cur`:
     - Nếu chưa clone → tạo `Node(neighbor.val)`, map, enqueue
     - Append `cloned[neighbor]` vào `cloned[cur].neighbors`

## 5. Code Python

```python
class Node:
    def __init__(self, val=0, neighbors=None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []


def cloneGraph(node: "Node") -> "Node":
    if not node:
        return None

    cloned: dict[Node, Node] = {node: Node(node.val)}
    queue = [node]

    while queue:
        cur = queue.pop(0)

        for neighbor in cur.neighbors:
            if neighbor not in cloned:
                cloned[neighbor] = Node(neighbor.val)
                queue.append(neighbor)

            cloned[cur].neighbors.append(cloned[neighbor])

    return cloned[node]
```

DFS tương tự — recurse neighbors, map lazy create.

## 6. Trace — 2 nodes mutual neighbors

1. Clone node 1 → map {1: 1'}
2. Neighbor 2 → create 2', map {1:1', 2:2'}
3. 1'.neighbors = [2']
4. Process 2 → 2'.neighbors = [1'] (đã có trong map)

## 7. Phân tích độ phức tạp

+ **Time O(V + E)**: Visit mỗi node và edge một lần
+ **Space O(V)**: Map + queue/stack
