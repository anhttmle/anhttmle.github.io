*Bài này áp dụng **Fast & Slow Pointer** từ [DSA Understanding – Part 8](/dsafundamental/2018/07/20/DSA-08.html).*

## 1. Đề bài đầy đủ

Cho `head` của singly linked list **không rỗng**. Trả về **middle node** của list.

Nếu có hai middle (số node chẵn), trả về node **thứ hai** (ví dụ [1,2,3,4,5,6] → node 4).

## 2. Ví dụ minh hoạ

| List | Output node |
|------|-------------|
| 1→2→3→4→5 | 3 |
| 1→2→3→4→5→6 | 4 |
| 1→2 | 2 |

## 3. Nhận diện pattern

+ Một pass, không đếm length trước → fast/slow
+ `slow += 1`, `fast += 2` mỗi vòng
+ Điều kiện `while fast and fast.next` → chẵn node lấy slow thứ hai

## 4. Hướng tiếp cận từng bước

1. `slow = fast = head`
2. Khi `fast` và `fast.next` còn tồn tại:
   - `slow = slow.next`
   - `fast = fast.next.next`
3. Trả `slow`

## 5. Code Python

```python
def middleNode(head):
    slow = fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

    return slow
```

## 6. Trace through 1→2→3→4→5→6

| step | slow | fast |
|------|------|------|
| 0 | 1 | 1 |
| 1 | 2 | 3 |
| 2 | 3 | 5 |
| 3 | 4 | null | fast.next null → dừng, **return 4** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Một lần duyệt
+ **Space O(1)**

Đếm length rồi đi n/2 bước cũng O(n) nhưng hai pass.

## 8. Biến thể

+ Lấy node **đầu tiên** khi chẵn: `while fast.next and fast.next.next`
+ **Remove Nth From End** (#19): fast đi n bước trước slow
+ **Palindrome Linked List** (#234): slow tới giữa rồi reverse nửa sau
