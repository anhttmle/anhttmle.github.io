Chào các bạn, hôm nay ta học **Sliding Window** — pattern tối ưu nhiều bài subarray/substring với **O(n)**.

## 1. Fixed Window:

Window có kích thước **k cố định**, trượt từ trái sang phải. Mỗi bước: bỏ phần tử ra khỏi window, thêm phần tử mới vào.

{% include dsa14-fixed-window-demo.html %}

Template:
1. Tính sum/window state cho window đầu `[0..k-1]`
2. Loop `i` từ `k` đến `n-1`: update state, so sánh kết quả

**Time**: O(n), **Space**: O(1)

## 2. Ví dụ:

+ **Maximum Average Subarray I** (LeetCode #643): max sum window size k
+ **Maximum Sum Subarray of Size K**: classic fixed window
+ **Find All Anagrams in String**: fixed window + frequency count

---

## Common Mistakes: Fixed Window

- **Window size k > n**: Edge case trả về empty hoặc 0.
- **Recompute từ đầu mỗi window**: O(n×k) — phải update incrementally O(1).
- **Nhầm fixed vs variable**: Fixed window size không đổi; variable expand/shrink.
