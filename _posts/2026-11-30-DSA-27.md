Chào các bạn, đây là bài cuối series **DSA Understanding**. Hôm nay ta xem cách biểu diễn graph bằng **Adjacency List** — format phổ biến nhất cho sparse graphs.

## 1. Adjacency List:

Mỗi node lưu **list các neighbors**:

```
0 → [1, 2]
1 → [0, 3]
2 → [0, 3]
3 → [1, 2]
```

{% include dsa27-adjacency-list-demo.html %}

+ **Space**: O(V + E) — hiệu quả hơn adjacency matrix O(V²) khi graph sparse
+ **Check edge (u,v)**: O(degree(u))

## 2. Adjacency List vs Matrix:

| | List | Matrix |
|---|------|--------|
| Space | O(V+E) | O(V²) |
| Add edge | O(1) | O(1) |
| Check edge | O(degree) | O(1) |
| Best for | Sparse graph | Dense graph |

## 3. Graph Traversal:

**BFS/DFS** trên adjacency list — O(V + E):

```python
def bfs(start, adj):
    queue = [start]
    visited = {start}
    while queue:
        node = queue.pop(0)
        for neighbor in adj[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```

## 4. Kết luận series:

Chúng ta đã đi qua toàn bộ lộ trình DSA: **Array** → **Stack/Queue** → **Hashing** → **Two Pointer** → **Prefix Sum** → **Sorting** → **Linked List** → **Sliding Window** → **Binary Search** → **Tree** → **Recursion** → **Heap** → **Backtracking** → **DP** → **Graph**.

Mỗi pattern là công cụ trong toolbox — practice sẽ giúp nhận diện pattern nhanh khi gặp bài mới.

## Common Mistakes: Adjacency List

- **Undirected graph**: Add edge cả hai chiều `adj[u].append(v)` và `adj[v].append(u)`.
- **Directed graph**: Chỉ add một chiều.
- **Self-loop / multi-edge**: Check đề bài có cho phép không.
