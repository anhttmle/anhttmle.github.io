Chào các bạn, **Backtracking** là systematic search kết hợp recursion — thử một choice, nếu không work thì **undo** (backtrack) và thử choice khác.

## 1. Backtracking Template:

```
def backtrack(state):
    if is_complete(state):
        record solution
        return
    for choice in choices:
        if is_valid(choice):
            make(choice)
            backtrack(state)
            undo(choice)  # backtrack
```

## 3. Classic Problems:

+ **N-Queens**: place queen row by row, backtrack khi conflict
+ **Permutations / Combinations / Subsets**
+ **Word Search** trên grid
+ **Sudoku Solver**

**Time**: exponential trong worst case — pruning giảm search space đáng kể.

---

## Common Mistakes: Backtracking

- **Quên undo**: Phải revert state sau mỗi recursive call.
- **Không prune sớm**: Check invalid sớm thay vì explore hết rồi mới check.
- **Duplicate solutions**: Dùng start index hoặc sort + skip duplicate (Combinations).
