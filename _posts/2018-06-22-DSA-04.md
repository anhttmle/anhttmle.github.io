Chào các bạn, bạn từng **Ctrl+Z** để hoàn tác trong Word chưa? Máy tính nhớ thao tác vừa làm và undo theo thứ tự **ngược lại** — thao tác cuối cùng bị hoàn tác trước. Đó chính là hành vi của **Stack**. Hôm nay ta học Stack và "người anh em" của nó — **Queue** (hàng đợi).

## 1. Intuition

**Stack (LIFO — Last In, First Out):**
+ Chồng đĩa: đặt đĩa lên trên cùng, lấy cũng lấy từ trên cùng
+ Trình duyệt: nút Back quay về trang **vừa vào gần nhất**

**Queue (FIFO — First In, First Out):**
+ Hàng đợi mua vé: người vào trước được phục vụ trước
+ In ấn: tài liệu gửi trước in trước

## 2. Stack — cách hoạt động từng bước

| Thao tác | Mô tả | Độ phức tạp |
|----------|-------|-------------|
| `push(x)` | Thêm x lên **top** | O(1) |
| `pop()` | Lấy phần tử top ra | O(1) |
| `peek()` | Xem top, không lấy | O(1) |

**Trace through:** push 5, push 3, pop()

1. push(5): stack = `[5]`, top = 5
2. push(3): stack = `[5, 3]`, top = 3
3. pop(): lấy 3 ra, stack = `[5]`, top = 5

## 3. Queue — cách hoạt động từng bước

| Thao tác | Mô tả | Độ phức tạp |
|----------|-------|-------------|
| `enqueue(x)` | Thêm x vào **rear** (cuối) | O(1) |
| `dequeue()` | Lấy phần tử **front** (đầu) | O(1)* |
| `peek()` | Xem front | O(1) |

*Với array thuần, `pop(0)` là O(n). Dùng **circular buffer** hoặc `collections.deque` để O(1).

## 4. Tại sao Stack phù hợp kiểm tra ngoặc?

**Invariant:** Stack luôn chứa các ngoặc mở **chưa được đóng**, theo thứ tự từ dưới lên.

Với chuỗi `"({[]})"`:
1. `(` → push
2. `{` → push
3. `[` → push
4. `]` → pop, khớp với `[` ✓
5. `}` → pop, khớp với `{` ✓
6. `)` → pop, khớp với `(` ✓
7. Stack rỗng → **hợp lệ**

Nếu gặp `)` khi top là `[` → không khớp → **không hợp lệ**.

**Tại sao đúng?** Ngoặc đóng gần nhất phải khớp ngoặc mở gần nhất → LIFO → Stack.

## 5. Phân tích độ phức tạp

+ Stack/Queue operations: **O(1)** mỗi thao tác (với implementation đúng)
+ Valid Parentheses: duyệt n ký tự, mỗi ký tự push/pop tối đa 1 lần → **O(n)** time, **O(n)** space

## Common Mistakes: Stack & Queue

- **Dùng Python list làm queue**: `pop(0)` là O(n). Dùng `deque.popleft()`.
- **Stack overflow**: Recursion sâu = call stack đầy. Chuyển sang iterative + explicit stack.
- **Nhầm LIFO/FIFO**: Undo = Stack; hàng đợi = Queue.
- **Quên check stack rỗng khi pop**: Luôn kiểm tra trước khi pop.
