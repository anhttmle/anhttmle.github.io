Chào các bạn, tiếp nối phần array, hôm nay ta tìm hiểu hai cấu trúc dữ liệu tuyến tính cơ bản: **Stack** và **Queue**. Cả hai đều có thể implement bằng array hoặc linked list, và xuất hiện khắp nơi trong lập trình thực tế.

## 1. Stack (LIFO):

**Stack** tuân theo nguyên tắc **LIFO** (Last In, First Out) — phần tử vào sau ra trước, giống chồng đĩa.

+ **push(x)**: thêm phần tử lên top — O(1)
+ **pop()**: lấy phần tử ở top — O(1)
+ **peek()**: xem top không lấy — O(1)

**Use cases**: Undo/Redo, call stack (recursion), DFS, bracket matching, expression evaluation.

## 2. Queue (FIFO):

**Queue** tuân theo **FIFO** (First In, First Out) — hàng đợi, vào trước ra trước.

+ **enqueue(x)**: thêm vào rear — O(1)
+ **dequeue()**: lấy phần tử front — O(1)
+ **peek()**: xem front — O(1)

**Use cases**: BFS, task scheduling, message queue, printer queue.

## 3. Implementation:

Cả Stack và Queue đều implement hiệu quả bằng **dynamic array** hoặc **linked list**:

+ Array-based: push/pop O(1) amortized; queue cần circular buffer để dequeue O(1)
+ Linked list-based: tất cả operations O(1) nếu có con trỏ head/tail

> **Lưu ý**: Python `list` dùng làm stack (append/pop), nhưng **không phù hợp làm queue** vì `pop(0)` là O(n). Dùng `collections.deque` cho queue.

## Common Mistakes: Stack & Queue

- **Dùng Python list làm queue**: `pop(0)` O(n). Dùng `deque` với `popleft()`.
- **Stack overflow**: Recursion sâu = call stack overflow. Chuyển sang iterative + explicit stack.
- **Nhầm LIFO/FIFO**: Stack = undo (mới nhất trước), Queue = BFS (cũ nhất trước).
