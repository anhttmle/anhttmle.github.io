Chào các bạn, để xử lý tree ta cần biết cách **duyệt** (traverse) tất cả nodes. Hai cách chính: **DFS** và **BFS**.

## 1. DFS (Depth-First Search):

Đi sâu nhất có thể trước khi backtrack. Ba thứ tự:

+ **Pre-order**: root → left → right
+ **In-order**: left → root → right (BST → sorted order)
+ **Post-order**: left → right → root

Implement bằng **recursion** hoặc **explicit stack**.

## 2. BFS (Breadth-First Search):

Duyệt **level-by-level** từ root. Dùng **Queue**:

1. Enqueue root
2. Dequeue node, process, enqueue children

## 3. So sánh:

| | DFS | BFS |
|---|-----|-----|
| Data structure | Stack / recursion | Queue |
| Space | O(h) height | O(w) max width |
| Use case | Path, backtracking | Shortest path (unweighted), level order |

**Time**: O(n) cho cả hai — visit mỗi node một lần.

---

## Common Mistakes: Tree Traversal

- **DFS stack overflow**: Tree sâu → dùng iterative DFS với explicit stack.
- **BFS null children**: Chỉ enqueue non-null children.
- **In-order on non-BST**: In-order chỉ cho sorted order khi tree là BST.
