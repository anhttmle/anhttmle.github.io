Chào các bạn, đây là bài cuối series **DSA Understanding**. Grid biểu diễn graph tốt khi có cấu trúc lưới; nhưng mạng xã hội, dependency packages, sơ đồ khóa học — node nối **tùy ý**, thưa — cần **Adjacency List**: mỗi node lưu danh sách neighbors.

## 1. Intuition

Danh bạ điện thoại: tên bạn → list số bạn bè. Muốn biết "Ai là bạn của Alice?" — mở entry Alice, đọc list. Không cần ma trận N×N (phần lớn ô trống nếu ít kết bạn).

**Adjacency List** = danh bạ graph: `node → [neighbor1, neighbor2, …]`

## 2. Cách hoạt động — từng bước

**Ví dụ undirected graph 4 nodes:**

```
0 → [1, 2]
1 → [0, 3]
2 → [0, 3]
3 → [1, 2]
```

**Build list:**

1. Khởi tạo `adj = {i: [] for i in range(n)}`
2. Với mỗi edge `(u, v)`: `adj[u].append(v)`; nếu undirected: `adj[v].append(u)`

**BFS traversal từ node 0:**

1. Queue `[0]`, visited `{0}`
2. Dequeue 0 → process → enqueue neighbors 1, 2 chưa visit
3. Dequeue 1 → enqueue 3 → …

**So sánh Adjacency List vs Matrix:**

| | List | Matrix |
|---|------|--------|
| Space | O(V + E) | O(V²) |
| Add edge | O(1) | O(1) |
| Check edge (u,v) | O(degree(u)) | O(1) |
| Best for | Sparse graph | Dense graph |

## 3. Tại sao giải thuật này đúng?

**BFS/DFS trên adjacency list** visit mỗi node và mỗi edge đúng một lần (với visited set):

+ **BFS:** Queue đảm bảo explore theo distance — shortest path unweighted
+ **DFS:** Stack/recursion đi sâu — cycle detection, topological sort

Clone Graph (#133): BFS/DFS + Hash Map `old_node → new_node` — mỗi node gốc map đúng một bản sao, neighbors copy theo edges gốc.

Course Schedule (#207): Directed graph + **Kahn's BFS** (in-degree) hoặc **DFS cycle detection** — có cycle ⟺ không topological sort được ⟺ không hoàn thành khóa.

## 4. Phân tích độ phức tạp

| Thao tác | Adjacency List |
|----------|----------------|
| BFS / DFS | O(V + E) |
| Build từ edge list | O(E) |
| Space | O(V + E) |

Sparse graph (E << V²): list tiết kiệm memory so với matrix.

## Common Mistakes: Adjacency List

- **Undirected graph**: Add edge **cả hai chiều** `adj[u].append(v)` và `adj[v].append(u)`.
- **Directed graph**: Chỉ add một chiều theo hướng edge.
- **Self-loop / multi-edge**: Đọc đề — có cho phép không?
- **Quên visited trong DFS cycle detect**: Course Schedule cần track node đang trong recursion stack (gray) vs đã xử lý (black).
