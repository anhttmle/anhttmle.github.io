Chào các bạn, bước vào **Graph** — cấu trúc mô hình networks, maps, dependencies. Bài này xem graph biểu diễn dạng **matrix** (grid).

## 1. Grid as Graph:

Mỗi cell là node, edge tới 4 neighbors (up, down, left, right). Cell `0` = wall (blocked).

{% include dsa26-graph-matrix-demo.html %}

## 2. Matrix DFS:

+ Dùng recursion hoặc stack
+ Mark **visited** để tránh cycle/lặp
+ Explore connected components — **Number of Islands**

```python
def dfs(r, c):
    if out_of_bounds or visited or grid[r][c] == 0:
        return
    visited.add((r, c))
    for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
        dfs(r+dr, c+dc)
```

## 3. Matrix BFS:

+ Dùng queue — tìm **shortest path** trên unweighted grid
+ **Rotting Oranges**, **Word Ladder** (implicit graph)

**Time**: O(m × n), **Space**: O(m × n) cho visited set

---

## Common Mistakes: Matrix Graph

- **In-place visited**: Modify grid `0`→`#` thay vì visited set — tiết kiệm space.
- **8-direction vs 4-direction**: Đọc đề kỹ — diagonal có được không?
- **BFS vs DFS cho shortest path**: BFS trên unweighted graph; DFS không guarantee shortest.
