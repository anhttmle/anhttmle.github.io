Chào các bạn, sau Sorting ta có array sorted — giờ là lúc tận dụng **Binary Search** để tìm kiếm trong **O(log n)**.

## 1. Ý tưởng:

Mỗi bước so sánh target với phần tử giữa, loại bỏ **một nửa** search space:

+ `arr[mid] == target` → found
+ `arr[mid] < target` → search right half: `lo = mid + 1`
+ `arr[mid] > target` → search left half: `hi = mid - 1`

## 2. Template:

```python
lo, hi = 0, len(arr) - 1
while lo <= hi:
    mid = (lo + hi) // 2
    if arr[mid] == target: return mid
    elif arr[mid] < target: lo = mid + 1
    else: hi = mid - 1
return -1
```

**Time**: O(log n), **Space**: O(1)

> **Lưu ý**: `(lo + hi) // 2` có thể overflow với số rất lớn. Dùng `lo + (hi - lo) // 2`.

## 3. Điều kiện áp dụng:

+ Array **sorted** (hoặc monotonic property)
+ Search space có thể **chia đôi** và loại bỏ một nửa

---

## Common Mistakes: Binary Search

- **Infinite loop**: Dùng `lo = mid + 1` và `hi = mid - 1`, loop `while lo <= hi`.
- **Off-by-one mid**: Với even length, `(lo+hi)//2` chọn left mid — consistent với template.
- **Unsorted array**: Binary search chỉ work trên sorted/monotonic data.
