Chào các bạn, tiếp nối fixed window, hôm nay ta xem **Variable Window** — kích thước window thay đổi bằng expand/shrink.

## 1. Variable Window Template:

```
left = 0
for right in range(n):
    # expand: thêm arr[right] vào window
    while window_invalid:
        # shrink: bỏ arr[left], left++
    update result
```

## 2. Longest Substring Without Repeating:

{% include dsa15-variable-window-demo.html %}

+ **Expand** `right`: thêm ký tự vào set/map
+ **Shrink** `left`: khi gặp duplicate, thu hẹp window từ trái
+ Track max length

**Time**: O(n), **Space**: O(min(n, alphabet))

## 3. Biến thể:

+ **Minimum Window Substring**: shrink khi valid, tìm min length
+ **Max Consecutive Ones III**: at most k zeros trong window
+ **Sliding Window Maximum**: dùng deque — O(n)

---

## Common Mistakes: Variable Window

- **Shrink quá sớm/muộn**: Điều kiện while shrink phải chính xác (valid vs invalid).
- **Quên update result**: Update sau khi window valid, không phải mỗi expand.
- **Empty string edge case**: Handle n=0, k=0.
