Chào các bạn, tiếp nối Merge Sort, hôm nay ta xem **Quick Sort** — sort in-place phổ biến nhất — và **Bucket Sort** — sort phân phối cho input đặc biệt.

## 1. Quick Sort:

Chọn **pivot**, partition array: phần tử nhỏ hơn pivot sang trái, lớn hơn sang phải. Đệ quy trên hai phần.

{% include dsa12-quick-sort-demo.html %}

+ **Time**: O(n log n) average, O(n²) worst (pivot xấu)
+ **Space**: O(log n) recursion stack
+ **Stable**: No (in-place partition swap)
+ **In-place**: Yes

> **Lưu ý**: Python `sorted()` dùng Timsort (hybrid merge+insertion). C++ `std::sort` thường dùng introsort (quick+heap+insertion).

## 2. Bucket Sort:

Phân phối phần tử vào các **bucket** theo range, sort từng bucket riêng.

+ **Time**: O(n + k) với k = số bucket (uniform distribution)
+ **Space**: O(n + k)
+ **Use case**: Input trong range nhỏ biết trước (0..100), floating point uniform

## 3. Khi nào dùng sort nào?

| Tình huống | Sort |
|-----------|------|
| General purpose, in-place | Quick Sort |
| Guaranteed O(n log n) | Merge Sort |
| Nearly sorted, small n | Insertion Sort |
| Known small range | Bucket/Counting Sort |

## Common Mistakes: Quick & Bucket Sort

- **Quick Sort worst case**: Sorted array + pivot đầu tiên → O(n²). Dùng random pivot hoặc median-of-three.
- **Bucket Sort không universal**: Chỉ hiệu quả khi input phân bố đều trong range.
- **Quên stable requirement**: Quick Sort không stable — cần Merge Sort nếu bài yêu cầu stability.
