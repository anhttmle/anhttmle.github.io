Chào các bạn, sau Stack và Queue, hôm nay ta tìm hiểu một cấu trúc dữ liệu mạnh mẽ hơn nhiều: **Hash Map** và **Hash Set** — cho phép lookup, insert, delete với độ phức tạp **O(1)** average.

## 1. Hash Map:

**Hash Map** (Dictionary trong Python, HashMap trong Java, Object/Map trong JavaScript) lưu cặp **key-value**. Mỗi key là duy nhất, map tới một value.

+ **get(key)**: lấy value — O(1) average
+ **put(key, value)**: thêm/cập nhật — O(1) average
+ **remove(key)**: xóa — O(1) average

## 2. Hash Set:

**Hash Set** chỉ lưu **keys** (không có value), đảm bảo **uniqueness** — không trùng lặp phần tử.

+ **add(x)**: thêm phần tử — O(1) average
+ **contains(x)**: kiểm tra tồn tại — O(1) average
+ **remove(x)**: xóa — O(1) average

**Use cases**: deduplication, membership test, Two Sum pattern, graph visited set.

## 3. Hash Function:

Hash function chuyển key bất kỳ thành index trong array (bucket):

\\[
\text{index} = \text{hash}(\text{key}) \mod \text{table\_size}
\\]

Hash function tốt phân bố đều, giảm collision. Python dùng `hash()` built-in; Java dùng `hashCode()`.

> **Lưu ý**: Keys phải **immutable** (int, str, tuple). List không làm key được vì mutable → hash thay đổi.

## 4. Ví dụ: Two Sum (LeetCode #1)

Duyệt array, với mỗi `nums[i]` kiểm tra `target - nums[i]` đã có trong Hash Map chưa — O(n) time, O(n) space.

## Common Mistakes: Hash Map & Hash Set

- **Worst case O(n)**: Khi tất cả keys collision vào cùng bucket, lookup thành O(n).
- **Mutable key**: Không dùng list/dict làm key trong Python.
- **Hash Set vs Sort**: Cần uniqueness check O(1) → Hash Set. Cần sorted order → sort O(n log n).
