*Bài này áp dụng **2D Dynamic Programming** từ [DSA Understanding – Part 25](/dsafundamental/2018/11/16/DSA-25.html).*

## 1. Đề bài đầy đủ

Cho hai chuỗi `text1` và `text2`. Trả về độ dài **Longest Common Subsequence (LCS)** — dãy con **không cần liên tiếp**, giữ thứ tự.

## 2. Ví dụ minh hoạ

| text1 | text2 | Output | LCS |
|-------|-------|--------|-----|
| "abcde" | "ace" | 3 | "ace" |
| "abc" | "abc" | 3 | "abc" |
| "abc" | "def" | 0 | "" |

## 3. Nhận diện pattern

+ So sánh hai chuỗi → **2D DP** `dp[i][j]` trên prefix `text1[0:i]`, `text2[0:j]`
+ Khớp ký tự cuối → kéo dài LCS +1
+ Không khớp → max(bỏ ký tự text1 hoặc text2)

## 4. Hướng tiếp cận từng bước

1. `dp[i][j]` = LCS của `text1[:i]` và `text2[:j]`
2. Nếu `text1[i-1] == text2[j-1]`: `dp[i][j] = dp[i-1][j-1] + 1`
3. Else: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
4. Answer: `dp[m][n]`

## 5. Code Python

```python
def longestCommonSubsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]
```

## 6. Trace through "ace" vs "abcde" (text2 vs text1)

So khớp tại 'a','c','e' — dp tăng dần trên đường chéo:

+ dp[1][1]: 'a'=='a' → 1
+ dp[2][3]: 'c'=='c' → dp[1][2]+1 = 2
+ dp[3][5]: 'e'=='e' → **3**

## 7. Phân tích độ phức tạp

+ **Time O(m × n)**
+ **Space O(m × n)**; rolling row → O(min(m,n))

## 8. Biến thể

+ **Longest Common Substring** (#718): Phải liên tiếp — reset khi không khớp
+ **Edit Distance** (#72): Insert/delete/replace — transition khác
+ **Delete Operation for Two Strings** (#583): m+n−2×LCS
