Chào các bạn, hôm nay ta học **Prefix Sum** — kỹ thuật preprocess array để trả lời range sum query trong **O(1)**.

## 1. 1D Prefix Sum:

Định nghĩa prefix array `P` với `P[0] = 0`:

\\[
P[i+1] = P[i] + arr[i]
\\]

Tổng subarray từ index `l` đến `r` (inclusive):

\\[
\text{sum}(l, r) = P[r+1] - P[l]
\\]

## 2. Preprocess vs Query:

+ **Build prefix**: O(n) một lần
+ **Range query**: O(1) mỗi query
+ **Tổng k queries**: O(n + k) thay vì O(n × k)

## 3. Ví dụ bài toán:

+ **Range Sum Query - Immutable** (LeetCode #303)
+ **Subarray Sum Equals K**: dùng prefix sum + Hash Map đếm
+ **Product of Array Except Self**: biến thể prefix product

---

## Common Mistakes: 1D Prefix Sum

- **P[0] = 0**: Quên sentinel 0 ở đầu → công thức range sum sai với l=0.
- **Index off-by-one**: sum(l..r) = P[r+1]-P[l], không phải P[r]-P[l-1].
- **Overflow**: Với số lớn, dùng long/int64 cho prefix array.
