*Bài này áp dụng **Hash Map** từ [DSA Understanding – Part 5](/dsafundamental/2018/06/29/DSA-05.html).*

## 1. Đề bài đầy đủ

Cho mảng số nguyên `nums` và số nguyên `target`. Trả về **index** của **hai số** sao cho tổng bằng `target`.

Giả sử mỗi input có **đúng một** cặp nghiệm, và **không** dùng cùng phần tử hai lần.

## 2. Ví dụ minh hoạ

| nums | target | Output | Giải thích |
|------|--------|--------|------------|
| [2, 7, 11, 15] | 9 | [0, 1] | 2 + 7 = 9 |
| [3, 2, 4] | 6 | [1, 2] | 2 + 4 = 6 |
| [3, 3] | 6 | [0, 1] | 3 + 3 = 6 |

## 3. Nhận diện pattern

+ Cần tìm `a + b = target` → với mỗi `a`, cần biết `target - a` đã gặp chưa
+ **Complement lookup** → **Hash Map** `{value: index}`
+ Nested loop O(n²) → Hash Map O(n)

## 4. Hướng tiếp cận từng bước

1. Tạo map rỗng `seen = {}`
2. Duyệt `i`, `num` trong `enumerate(nums)`:
   - `need = target - num`
   - Nếu `need in seen` → trả `[seen[need], i]`
   - Ngược lại: `seen[num] = i` (lưu sau khi check để không dùng cùng index)

**Tại sao lưu sau khi check?** Tránh dùng cùng phần tử hai lần (vd: target=6, num=3, need=3 — phải dùng hai index khác nhau).

## 5. Code Python

```python
def twoSum(nums: list[int], target: int) -> list[int]:
    seen = {}  # value -> index

    for i, num in enumerate(nums):
        need = target - num
        if need in seen:
            return [seen[need], i]
        seen[num] = i

    return []  # không có (đề bài guarantee có)
```

## 6. Trace through nums=[2,7,11,15], target=9

| i | num | need | seen trước | Hành động |
|---|-----|------|------------|-----------|
| 0 | 2 | 7 | {} | 7 chưa có → seen={2:0} |
| 1 | 7 | 2 | {2:0} | 2 có trong seen → **return [0,1]** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Duyệt 1 lần, mỗi lookup/insert O(1) average
+ **Space O(n)**: Map lưu tối đa n phần tử

## 8. Biến thể

+ **Two Sum II** (#167): Array **đã sort** → Two Pointer thay Hash Map
+ **Three Sum** (#15): Cố định 1 phần tử + Two Sum
+ **Four Sum** (#18): Mở rộng tương tự
