*Bài này áp dụng **Two Pointer – Opposite Direction** từ [DSA Understanding – Part 7](/dsafundamental/2018/07/13/DSA-07.html).*

## 1. Đề bài đầy đủ

Cho mảng không âm `height` — `height[i]` là chiều cao vách tại cột `i`. Tìm hai cột sao cho thùng chứa (độ rộng × **chiều cao nước** = min hai vách) có **diện tích lớn nhất**.

Trả về diện tích tối đa (không trả index).

## 2. Ví dụ minh hoạ

| height | Output | Giải thích |
|--------|--------|------------|
| [1,8,6,2,5,4,8,3,7] | 49 | vách 8 và 7, width 7, min(8,7)×7=49 |
| [1,1] | 1 | |
| [4,3,2,1,4] | 16 | hai vách 4, width 4 |

## 3. Nhận diện pattern

+ Hai index hai đầu → opposite pointer
+ Diện tích = `(right - left) * min(height[left], height[right])`
+ **Greedy move**: Thu hẹp cạnh **thấp hơn** — cạnh cao giữ lại mới có cơ hội tăng min height

## 4. Hướng tiếp cận từng bước

1. `left = 0`, `right = n-1`, `best = 0`
2. `while left < right`:
   - Cập nhật `best` với diện tích hiện tại
   - Nếu `height[left] < height[right]` → `left++` else `right--`

**Tại sao di chuyển cạnh thấp?** Giữ cạnh cao và thu hẹp width luôn làm min(height) không tăng (vẫn bị giới bởi cạnh thấp còn lại).

## 5. Code Python

```python
def maxArea(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    best = 0

    while left < right:
        w = right - left
        h = min(height[left], height[right])
        best = max(best, w * h)
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return best
```

## 6. Trace through height=[1,8,6,2,5,4,8,3,7] (vài bước)

| left | right | area | Move |
|------|-------|------|------|
| 0 | 8 | min(1,7)×8=8 | left (1<7) |
| 1 | 8 | min(8,7)×7=49 | right (8>7) |
| ... | ... | best≥49 | tiếp tục |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Mỗi pointer tối đa n bước
+ **Space O(1)**

Brute force mọi cặp O(n²) bị loại bởi greedy chứng minh trên.
