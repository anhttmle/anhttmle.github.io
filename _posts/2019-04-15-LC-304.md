*Bài này áp dụng **2D Prefix Sum** từ [DSA Understanding – Part 10](/dsafundamental/2018/08/03/DSA-10.html).*

## 1. Đề bài đầy đủ

Implement class `NumMatrix`:

+ `NumMatrix(matrix)`: Khởi tạo từ matrix 2D số nguyên.
+ `sumRegion(row1, col1, row2, col2)`: Tổng các ô trong hình chữ nhật góc `(row1,col1)` và `(row2,col2)` inclusive.

Matrix không đổi sau khởi tạo; nhiều query.

## 2. Ví dụ minh hoạ

```
matrix = [
  [3, 0, 1, 4, 2],
  [5, 6, 3, 2, 1],
  [1, 2, 0, 1, 5],
  [4, 1, 0, 1, 7],
  [1, 0, 3, 0, 5]
]
sumRegion(2, 1, 4, 3) → 8
sumRegion(1, 1, 2, 2) → 11
sumRegion(1, 2, 2, 4) → 12
```

## 3. Nhận diện pattern

+ Submatrix sum lặp lại → **2D prefix** P size (m+1)×(n+1)
+ Build: inclusion-exclusion 4 neighbor
+ Query: trừ hai dải, cộng góc chung

## 4. Hướng tiếp cận từng bước

1. `m, n = len(matrix), len(matrix[0])`
2. `P[i+1][j+1] = matrix[i][j] + P[i][j+1] + P[i+1][j] - P[i][j]` (loop i,j)
3. `sumRegion(r1,c1,r2,c2)`:
   `P[r2+1][c2+1] - P[r1][c2+1] - P[r2+1][c1] + P[r1][c1]`

## 5. Code Python

```python
class NumMatrix:
    def __init__(self, matrix: list[list[int]]):
        if not matrix or not matrix[0]:
            self.p = [[0]]
            return
        m, n = len(matrix), len(matrix[0])
        self.p = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                self.p[i + 1][j + 1] = (
                    matrix[i][j]
                    + self.p[i][j + 1]
                    + self.p[i + 1][j]
                    - self.p[i][j]
                )

    def sumRegion(
        self, row1: int, col1: int, row2: int, col2: int
    ) -> int:
        p = self.p
        return (
            p[row2 + 1][col2 + 1]
            - p[row1][col2 + 1]
            - p[row2 + 1][col1]
            + p[row1][col1]
        )
```

## 6. Trace sumRegion(2,1,4,3) trên ví dụ đề

Sau build P, lấy bốn góc theo công thức → tổng các ô hàng 2–4, cột 1–3 = **8** (khớp đề).

Kiểm tra tay: ô (2,1)=2, (2,2)=0, (2,3)=1, (3,1)=1, (3,2)=0, (3,3)=1, (4,1)=0, (4,2)=3, (4,3)=0 → 2+0+1+1+0+1+0+3+0 = 8.

## 7. Phân tích độ phức tạp

+ **Init O(m × n)**
+ **sumRegion O(1)**
+ **Space O(m × n)** cho P

## 8. Biến thể

+ **Range Sum Query 2D - Mutable** (#308): Segment tree / Fenwick 2D
+ **Maximal Rectangle** (#85): Histogram + stack trên từng hàng prefix
+ **Count Square Submatrices** (#1277): DP + prefix
