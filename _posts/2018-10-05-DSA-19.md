Chào các bạn, **Binary Search Tree** (**BST**) là binary tree với property sắp xếp — nền tảng cho TreeMap, ordered sets, và nhiều giải thuật.

## 1. BST Property:

Với mọi node:
+ Mọi giá trị **left subtree** < node value
+ Mọi giá trị **right subtree** > node value

## 2. Insert:

Tìm vị trí leaf phù hợp theo property, gắn node mới — O(h) với h = height.

## 3. Remove — 3 cases:

1. **Leaf node**: xóa trực tiếp
2. **One child**: thay node bằng child
3. **Two children**: thay bằng **inorder successor** (min của right subtree) hoặc **inorder predecessor**

+ **Search**: O(h) average O(log n), worst O(n) nếu skewed
+ **Insert/Delete**: O(h)

> **Lưu ý**: BST thông thường không self-balance. **AVL Tree** và **Red-Black Tree** giữ height O(log n).

---

## Common Mistakes: BST

- **Duplicate values**: Convention: duplicates vào left hoặc right — thống nhất.
- **Skewed tree**: Insert sorted sequence → linked list O(n) height. Cần balanced BST.
- **Remove two children**: Phải copy value từ successor, rồi delete successor node.
