## Bellman Equation for MRPs
> The Markov property gives a recursive decomposition: the value of a state splits into the immediate reward plus the discounted value of successor states.

For every state $s \in \mathcal{S}$:

$$
V(s) = R(s) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s)\,V(s')
$$

The first term \(R(s)\) captures the immediate reward; the second term captures the expected discounted future reward, weighted by the transition probabilities.

## Iterative Algorithm for MRP Value Computation
Dynamic programming provides a scalable alternative. We initialize all values to zero and repeatedly apply the Bellman equation as an update rule until convergence.

### Algorithm: Iterative Value Evaluation for an MRP

1. Initialize $V_0(s) = 0$ for all $s \in \mathcal{S}$.

2. For $k = 1, 2, \ldots$, until convergence, update every state:

$$
  V_k(s)=R(s) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s)\,V_{k-1}(s') \qquad \text{for all } s \in \mathcal{S}
$$

**Computational cost:** $O(|\mathcal{S}|^2)$ per iteration.

Each iteration applies one **Bellman backup** across all states, propagating value information one step further backward in time. This procedure converges to the true value function \(V\) when \(\gamma < 1\), or when the process terminates with probability 1.
