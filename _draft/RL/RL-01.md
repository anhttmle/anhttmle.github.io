# Concepts will be covered
- Agent & Environment
  - Observation & State space
    - Dynamics model
    - Rollout/Simulation: Kỹ thuật ước tính giá trị bằng cách lấy mẫu thay vì tính toán tổng lớn
    - State-value function (V(s))
    - State-action value function (Q(s, a))
  - Policy & Action space
    - Policy function - π: Deterministic or Stochastic
    - Policy model
    - Policy Iteration: Thuật toán bao gồm hai bước: đánh giá chính sách và cải thiện chính sách, đảm bảo sự cải thiện đơn điệu
    - Batch Policy Evaluation
  - Reward model
    - Value function
      - Analytical Solution: Sử dụng nghịch đảo ma trận để tìm hàm giá trị trực tiếp cho các không gian trạng thái nhỏ
      - Q-function
      - Value Iteration: Thuật toán hội tụ về giá trị tối ưu bằng cách lặp lại các toán tử Bellman
  - Decision Process
    - Bellman Equation
      - Bellman Backup Operator
    - Markov Decision Processes - MDPs
      - Dynamic Programming
      - Tabular MDP
    - Markov Reward Process - MRP
    - Markov property
    - Discount factor
    - History
    - Finite vs. Infinite Horizon: Phân biệt giữa bài toán có số bước giới hạn và bài toán kéo dài mãi mãi
- Methods
  - Monte Carlo Tree Search - MCTS
  - Proximal Policy Optimization - PPO
  - Evaluation and Control
  - Model-free learning vs Model-based learning
  - Temporal Difference (TD) learning
    - TD Target
    - TD Error
  - Monte Carlo methods: Sử dụng các mẫu trả về (returns) để cập nhật giá trị (35:34).
  - SARSA: Thuật toán on-policy.
  - Q-learning: Thuật toán off-policy.
  - Deep Q-Networks (DQN) và sự ổn định:
    - Deadly Triad: Ba yếu tố gây mất ổn định: Bootstrapping, Function Approximation và Off-policy learning (103:04).
    - Experience Replay (Bộ nhớ đệm kinh nghiệm): Lưu trữ và lấy mẫu lại các tuple (107:11).
    - Fixed Q-targets: Cố định mục tiêu để giảm sự dao động (107:03).
    - Convolutional Neural Networks (CNN): Kiến trúc xử lý hình ảnh (114:05). 
  - Exploration Strategy:
    - Epsilon-greedy: Phương pháp cân bằng giữa khám phá (exploration) và khai thác (exploitation)
    - Glee (Greedy in the Limit of Infinite Exploration): Điều kiện đảm bảo hội tụ tới tối ưu.
