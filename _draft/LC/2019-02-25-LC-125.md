*Bài này áp dụng **Two Pointer – Opposite Direction** từ [DSA Understanding – Part 7](/dsafundamental/2018/07/13/DSA-07.html).*

## 1. Đề bài đầy đủ

Cho chuỗi `s`. Trả về `true` nếu sau khi chỉ giữ chữ cái và chữ số, chuỗi là **palindrome** (đọc xuôi ngược như nhau). So sánh **không phân biệt hoa thường**.

## 2. Ví dụ minh hoạ

| s | Output |
|---|--------|
| "A man, a plan, a canal: Panama" | true |
| "race a car" | false |
| " " | true (chuỗi rỗng sau lọc) |

## 3. Nhận diện pattern

+ So sánh **hai đầu** chuỗi → opposite pointer
+ Ký tự không hợp lệ → **skip** (left++ hoặc right--) thay vì so sánh
+ `isalnum()` + `.lower()` cho chuẩn đề

## 4. Hướng tiếp cận từng bước

1. `left = 0`, `right = len(s) - 1`
2. `while left < right`:
   - Skip non-alphanumeric ở `left` / `right`
   - Nếu `lower(s[left]) != lower(s[right])` → false
   - `left++`, `right--`
3. Hết vòng → true

## 5. Code Python

```python
def isPalindrome(s: str) -> bool:
    left, right = 0, len(s) - 1

    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1

    return True
```

## 6. Trace through s="race a car"

| left | right | left char | right char | Kết quả |
|------|-------|-----------|------------|---------|
| 0 | 9 | r | r | khớp |
| ... | ... | ... | ... | ... |
| cuối | | e | a | **không khớp** → false |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Mỗi ký tự được left/right xử lý hữu hạn lần
+ **Space O(1)**: Không tạo chuỗi reversed (có thể O(n) nếu filter trước — không cần)

## 8. Biến thể

+ **Valid Palindrome II** (#680): Cho phép xóa tối đa 1 ký tự
+ **Palindrome Linked List** (#234): Fast/slow + reverse nửa sau
+ Chỉ chữ cái (bỏ số) — điều chỉnh điều kiện `isalpha()`
