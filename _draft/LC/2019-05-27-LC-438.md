*Bài này áp dụng **Fixed Sliding Window** từ [DSA Understanding – Part 14](/dsafundamental/2018/08/31/DSA-14.html).*

## 1. Đề bài đầy đủ

Cho hai chuỗi `s` và `p`. Trả về **danh sách index đầu** của mọi **anagram** của `p` trong `s` (substring cùng độ dài `len(p)`).

## 2. Ví dụ minh hoạ

| s | p | Output |
|---|---|--------|
| "cbaebabacd" | "abc" | [0, 6] |
| "abab" | "ab" | [0, 1, 2] |

## 3. Nhận diện pattern

+ Window size = `len(p)` cố định
+ So khớp **frequency** 26 chữ cái (hoặc Counter)
+ Slide: trừ ký tự ra, cộng ký tự vào

## 4. Hướng tiếp cận từng bước

1. Đếm `need` từ `p`, `window` cho ký tự đầu của `s`
2. `matches` = số chữ cái có cùng count (hoặc so sánh hai mảng)
3. Slide `right` từ `len(p)` đến cuối: bỏ `s[right-len(p)]`, thêm `s[right]`
4. Khi khớp → append `right - len(p)`

## 5. Code Python

```python
def findAnagrams(s: str, p: str) -> list[int]:
    if len(p) > len(s):
        return []

    need = [0] * 26
    window = [0] * 26
    a = ord("a")

    for ch in p:
        need[ord(ch) - a] += 1

    k = len(p)
    for i in range(k):
        window[ord(s[i]) - a] += 1

    result = []
    if window == need:
        result.append(0)

    for right in range(k, len(s)):
        left_ch = s[right - k]
        window[ord(left_ch) - a] -= 1
        window[ord(s[right]) - a] += 1
        if window == need:
            result.append(right - k + 1)

    return result
```

## 6. Trace s="cbaebabacd", p="abc"

+ Index 0: window "cba" ≠
+ Slide đến index 6: window "bac" → frequency khớp `abc` → **[0, 6]**

## 7. Phân tích độ phức tạp

+ **Time O(n)** — so sánh 26 ô mỗi bước O(1)
+ **Space O(1)** — bảng 26
