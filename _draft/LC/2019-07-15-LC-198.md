*Bài này áp dụng **1D Dynamic Programming** từ [DSA Understanding – Part 24](/dsafundamental/2018/11/09/DSA-24.html).*

## 1. Đề bài đầy đủ

Cho `nums` — `nums[i]` là số tiền ở nhà thứ i. **Không** cướp hai nhà **liền kề**. Trả về **tổng tiền tối đa** có thể cướp.

## 2. Ví dụ minh hoạ

| nums | Output | Giải thích |
|------|--------|------------|
| [1,2,3,1] | 4 | Cướp nhà 0 và 2: 1+3 |
| [2,7,9,3,1] | 12 | 2+9+1 |
| [2,1,1,2] | 4 | 2+2 (nhà 0 và 3) |

## 3. Nhận diện pattern

+ Tại nhà i: **cướp** (không cướp i−1) hoặc **bỏ qua** (lấy dp[i−1])
+ `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
+ Classic **1D DP** — optimal substructure trên prefix

## 4. Hướng tiếp cận từng bước

1. `dp[i]` = max tiền cướp từ nhà 0..i
2. Base: `dp[0] = nums[0]`, `dp[1] = max(nums[0], nums[1])`
3. Transition: cướp i → `dp[i-2]+nums[i]`; không cướp → `dp[i-1]`
4. Space O(1): `prev2, prev1` thay array

## 5. Code Python

```python
def rob(nums: list[int]) -> int:
    if len(nums) == 1:
        return nums[0]

    prev2, prev1 = nums[0], max(nums[0], nums[1])

    for i in range(2, len(nums)):
        curr = max(prev1, prev2 + nums[i])
        prev2, prev1 = prev1, curr

    return prev1
```

## 6. Trace through [2, 7, 9, 3, 1]

| i | nums[i] | prev2 | prev1 | curr |
|---|---------|-------|-------|------|
| 0 | 2 | — | 2 | — |
| 1 | 7 | 2 | 7 | — |
| 2 | 9 | 2 | 7 | max(7, 2+9)=11 |
| 3 | 3 | 7 | 11 | max(11, 7+3)=11 |
| 4 | 1 | 11 | 11 | max(11, 11+1)=**12** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Một pass
+ **Space O(1)**: Hai biến

## 8. Biến thể
