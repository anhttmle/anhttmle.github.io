*Bài này áp dụng **Binary Search on Range (lower bound)** từ [DSA Understanding – Part 17](/dsafundamental/2018/09/21/DSA-17.html).*

## 1. Đề bài đầy đủ

Cho `nums` sort tăng **không trùng** và `target`. Trả về index nếu có; nếu không, index **chèn** `target` để mảng vẫn sort.

## 2. Ví dụ minh hoạ

| nums | target | Output |
|------|--------|--------|
| [1,3,5,6] | 5 | 2 |
| [1,3,5,6] | 2 | 1 |
| [1,3,5,6] | 7 | 4 |

## 3. Nhận diện pattern

+ **Lower bound:** index đầu tiên `nums[i] >= target`
+ Trùng target → index đó; không trùng → vị trí chèn

## 4. Hướng tiếp cận từng bước

1. `lo = 0`, `hi = len(nums)` (half-open)
2. `while lo < hi`: so `nums[mid]` với `target`
3. `nums[mid] < target` → `lo = mid + 1`; else `hi = mid`
4. Trả `lo`

## 5. Code Python

```python
def searchInsert(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

## 6. Trace nums=[1,3,5,6], target=2

| lo | hi | mid | nums[mid] |
|----|----|-----|-----------|
| 0 | 4 | 2 | 5 ≥ 2 → hi=2 |
| 0 | 2 | 1 | 3 ≥ 2 → hi=1 |
| 0 | 1 | 0 | 1 < 2 → lo=1 |

→ **1**

## 7. Phân tích độ phức tạp

+ **Time O(log n)**
+ **Space O(1)**
