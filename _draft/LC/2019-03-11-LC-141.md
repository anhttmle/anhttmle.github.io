*Bài này áp dụng **Fast & Slow Pointer** từ [DSA Understanding – Part 8](/dsafundamental/2018/07/20/DSA-08.html).*

## 1. Đề bài đầy đủ

Cho `head` của linked list. Trả về `true` nếu list có **cycle** (một node `next` trỏ về node trước đó trên list).

## 2. Ví dụ minh hoạ

| Input | Output |
|-------|--------|
| 3→2→0→-4, tail -4 trỏ node 2 | true |
| 1→2, tail 2 trỏ node 1 | true |
| 1 | false |

## 3. Nhận diện pattern

+ Cấu trúc linked list + hỏi cycle → **Floyd** (tortoise & hare)
+ HashSet visited: O(n) space — Floyd O(1) space
+ Không biết độ dài cycle → không đếm bước được

## 4. Hướng tiếp cận từng bước

1. `slow = fast = head`
2. `while fast and fast.next`:
   - `slow = slow.next`
   - `fast = fast.next.next`
   - Nếu `slow == fast` → true
3. Fast ra null → false

## 5. Code Python

```python
def hasCycle(head) -> bool:
    slow = fast = head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True

    return False
```

## 6. Trace through 3→2→0→-4→(back to 2)

| step | slow | fast |
|------|------|------|
| 0 | 3 | 3 |
| 1 | 2 | 0 |
| 2 | 0 | 2 (wrap) |
| 3 | -4 | -4 | slow==fast → **true** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Trước khi vào cycle fast gặp slow; trong cycle tối đa O(λ) bước thêm
+ **Space O(1)**: Hai pointer

## 8. Biến thể

+ **Linked List Cycle II** (#142): Tìm node bắt đầu cycle — reset một pointer về head, cùng tốc độ
+ **Happy Number** (#202): Floyd trên sequence số, không phải list node
+ **Find Duplicate Number** (#287): Floyd trên index array
