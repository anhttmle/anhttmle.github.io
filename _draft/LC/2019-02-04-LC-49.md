*Bài này áp dụng **Hash Map grouping** từ [DSA Understanding – Part 6](/dsafundamental/2018/07/06/DSA-06.html).*

## 1. Đề bài đầy đủ

Cho mảng chuỗi `strs`. **Nhóm** các chuỗi là **anagram** với nhau (cùng ký tự, khác thứ tự). Trả về danh sách các nhóm (thứ tự không quan trọng).

## 2. Ví dụ minh hoạ

**Input:** `["eat","tea","tan","ate","nat","bat"]`

**Output:** `[["eat","tea","ate"], ["tan","nat"], ["bat"]]`

+ "eat", "tea", "ate" — cùng bộ {a,e,t}
+ "tan", "nat" — cùng bộ {a,n,t}
+ "bat" — một mình

## 3. Nhận diện pattern

+ **Grouping** theo "đặc trưng chung" → Hash Map
+ Anagram có cùng ký tự → **key = sorted string** hoặc **tuple đếm 26 chữ**

## 4. Hướng tiếp cận

1. Map `groups = {}`  # key → list of strings
2. Với mỗi `s` trong strs:
   - `key = tuple(sorted(s))` hoặc `"#".join(sorted(s))`
   - Nếu key chưa có → `groups[key] = []`
   - `groups[key].append(s)`
3. Trả `list(groups.values())`

**Tại sao sorted key đúng?** Mọi anagram cho cùng chuỗi sorted. "eat" → "aet", "tea" → "aet".

## 5. Code Python

```python
def groupAnagrams(strs: list[str]) -> list[list[str]]:
    groups = {}

    for s in strs:
        key = tuple(sorted(s))
        if key not in groups:
            groups[key] = []
        groups[key].append(s)

    return list(groups.values())
```

Dùng `defaultdict(list)` gọn hơn:

```python
from collections import defaultdict

def groupAnagrams(strs: list[str]) -> list[list[str]]:
    groups = defaultdict(list)
    for s in strs:
        groups[tuple(sorted(s))].append(s)
    return list(groups.values())
```

## 6. Trace through ["eat","tea","bat"]

| s | key sorted | groups |
|---|------------|--------|
| eat | ('a','e','t') | {key: [eat]} |
| tea | ('a','e','t') | {key: [eat, tea]} |
| bat | ('a','b','t') | + {bat key: [bat]} |

## 7. Phân tích độ phức tạp

+ **Time O(n × k log k)**: n chuỗi, mỗi chuỗi sort length k
+ Có thể O(n × k) với key = tuple đếm 26 chữ thay sort
+ **Space O(n × k)**: Lưu tất cả chuỗi trong map

## 8. Biến thể

+ **Valid Anagram** (#242): Check 2 chuỗi có anagram không
+ Key bằng frequency array nhanh hơn sort khi k lớn
