*Bài này áp dụng **Binary Search** từ [DSA Understanding – Part 16](/dsafundamental/2018/09/14/DSA-16.html).*

## 1. Đề bài đầy đủ

Cho `nums` **sort tăng dần** (không trùng) và `target`. Trả về **index** nếu `target` có trong mảng, ngược lại **-1**.

## 2. Ví dụ minh hoạ

| nums | target | Output |
|------|--------|--------|
| [-1,0,3,5,9,12] | 9 | 4 |
| [-1,0,3,5,9,12] | 2 | -1 |

## 3. Nhận diện pattern

+ Sorted array + tìm exact value → binary search chuẩn
+ O(log n) bắt buộc khi đề gợi ý hoặc n lớn

## 4. Hướng tiếp cận từng bước

1. `lo = 0`, `hi = len(nums) - 1`
2. `while lo <= hi`: `mid`, so sánh với `target`, thu `lo` hoặc `hi`
3. Hết vòng → -1

## 5. Code Python

```python
def search(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## 6. Trace nums=[-1,0,3,5,9,12], target=9

| lo | hi | mid | nums[mid] |
|----|----|-----|-----------|
| 0 | 5 | 2 | 3 → lo=3 |
| 3 | 5 | 4 | 9 → **return 4** |

## 7. Phân tích độ phức tạp

+ **Time O(log n)**
+ **Space O(1)**
