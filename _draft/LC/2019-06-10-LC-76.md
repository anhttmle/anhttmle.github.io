*Bài này áp dụng **Variable Sliding Window** từ [DSA Understanding – Part 15](/dsafundamental/2018/09/07/DSA-15.html).*

## 1. Đề bài đầy đủ

Cho `s` và `t`. Trả về **substring ngắn nhất** của `s` sao cho mọi ký tự trong `t` (kể cả trùng) đều có trong window. Nếu không có, trả `""`.

## 2. Ví dụ minh hoạ

| s | t | Output |
|---|---|--------|
| "ADOBECODEBANC" | "ABC" | "BANC" |
| "a" | "a" | "a" |
| "a" | "aa" | "" |

## 3. Nhận diện pattern

+ **Shortest** window **valid** → expand đến đủ, shrink khi vẫn valid
+ Frequency map cho `t` và window
+ `formed` / `required` đếm số loại ký tự đã đủ count

## 4. Hướng tiếp cận từng bước

1. Đếm `need` từ `t`, `required` = số key khác 0
2. Expand `right`: tăng `window[c]`, nếu khớp `need[c]` → `formed++`
3. Khi `formed == required`: cập nhật min, shrink `left` đến khi mất valid
4. Trả substring tại best `(start, start+len)`

## 5. Code Python

```python
def minWindow(s: str, t: str) -> str:
    if not t or not s:
        return ""

    need: dict[str, int] = {}
    for ch in t:
        need[ch] = need.get(ch, 0) + 1

    required = len(need)
    formed = 0
    window: dict[str, int] = {}

    best_len = float("inf")
    best_left = 0
    left = 0

    for right, ch in enumerate(s):
        window[ch] = window.get(ch, 0) + 1
        if ch in need and window[ch] == need[ch]:
            formed += 1

        while formed == required:
            if right - left + 1 < best_len:
                best_len = right - left + 1
                best_left = left
            left_ch = s[left]
            window[left_ch] -= 1
            if left_ch in need and window[left_ch] < need[left_ch]:
                formed -= 1
            left += 1

    if best_len == float("inf"):
        return ""
    return s[best_left : best_left + best_len]
```

## 6. Trace (rút gọn) s="ADOBECODEBANC", t="ABC"

+ Expand đến "ADOBEC" → đủ A,B,C → ghi nhận, shrink
+ Tiếp tục đến "BANC" ngắn nhất valid

## 7. Phân tích độ phức tạp

+ **Time O(|s| + |t|)** — mỗi con trỏ di chuyển tối đa n bước
+ **Space O(|s| + |t|)** cho map
