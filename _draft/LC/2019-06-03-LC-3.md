*Bài này áp dụng **Variable Sliding Window** từ [DSA Understanding – Part 15](/dsafundamental/2018/09/07/DSA-15.html).*

## 1. Đề bài đầy đủ

Cho chuỗi `s`. Trả về độ dài **substring dài nhất** không chứa ký tự lặp.

## 2. Ví dụ minh hoạ

| s | Output |
|---|--------|
| "abcabcbb" | 3 ("abc") |
| "bbbbb" | 1 |
| "pwwkew" | 3 ("wke") |

## 3. Nhận diện pattern

+ **Longest** subarray/substring thỏa điều kiện → variable window
+ Điều kiện: mọi ký tự trong window **unique**
+ Map `char → index` để shrink nhanh khi trùng

## 4. Hướng tiếp cận từng bước

1. `left = 0`, `best = 0`, `last_seen = {}`
2. Duyệt `right`, ký tự `c`:
   - Nếu `c` trong window (`last_seen[c] >= left`) → `left = last_seen[c] + 1`
   - `last_seen[c] = right`
   - `best = max(best, right - left + 1)`

## 5. Code Python

```python
def lengthOfLongestSubstring(s: str) -> int:
    last_seen: dict[str, int] = {}
    left = 0
    best = 0

    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best = max(best, right - left + 1)

    return best
```

## 6. Trace s="abcabcbb"

| right | ch | left | window | best |
|-------|-----|------|--------|------|
| 0 | a | 0 | a | 1 |
| 1 | b | 0 | ab | 2 |
| 2 | c | 0 | abc | 3 |
| 3 | a | 1 | bca | 3 |
| ... | | | | 3 |

## 7. Phân tích độ phức tạp

+ **Time O(n)**
+ **Space O(min(n, Σ))**
