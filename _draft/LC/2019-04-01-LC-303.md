*Bài này áp dụng **1D Prefix Sum** từ [DSA Understanding – Part 9](/dsafundamental/2018/07/27/DSA-09.html).*

## 1. Đề bài đầy đủ

Implement class `NumArray`:

+ `NumArray(nums)`: Khởi tạo từ mảng `nums` cố định.
+ `sumRange(left, right)`: Trả tổng `nums[left] + ... + nums[right]` (inclusive).

Giả sử nhiều query `sumRange`; `nums` không đổi sau khi khởi tạo.

## 2. Ví dụ minh hoạ

```
NumArray numArray = new NumArray([-2, 0, 3, -5, 2, -1]);
numArray.sumRange(0, 2);  // -2 + 0 + 3 = 1
numArray.sumRange(2, 5);  // 3 + (-5) + 2 + (-1) = -1
numArray.sumRange(0, 5);  // tổng cả mảng = -3
```

## 3. Nhận diện pattern

+ Nhiều **range sum query** trên mảng tĩnh → build **prefix** một lần
+ `P[0]=0`, `P[i+1]=P[i]+nums[i]`
+ Query: `P[right+1] - P[left]`

## 4. Hướng tiếp cận từng bước

1. Trong `__init__`: tạo `self.prefix` length `len(nums)+1`, prefix[0]=0
2. Loop i: `prefix[i+1] = prefix[i] + nums[i]`
3. `sumRange(l,r)`: return `prefix[r+1] - prefix[l]`

## 5. Code Python

```python
class NumArray:
    def __init__(self, nums: list[int]):
        self.prefix = [0]
        for x in nums:
            self.prefix.append(self.prefix[-1] + x)

    def sumRange(self, left: int, right: int) -> int:
        return self.prefix[right + 1] - self.prefix[left]
```

## 6. Trace through nums=[-2,0,3,-5,2,-1], sumRange(2,5)

Prefix P: [0, -2, -2, 1, -4, -2, -3]

+ `sumRange(2,5) = P[6] - P[2] = -3 - (-2) = -1` ✓

## 7. Phân tích độ phức tạp

+ **Init O(n)**: Build prefix
+ **sumRange O(1)**: Hai phép trừ
+ **Space O(n)**: Mảng prefix

q queries: O(n + q) vs O(n×q) cộng trực tiếp.

## 8. Biến thể

+ **Range Sum Query 2D** (#304): Prefix 2D
+ **Range Sum Query - Mutable** (#307): Fenwick / Segment Tree
+ **Maximum Subarray** (#53): Kadane, không chỉ sum query
