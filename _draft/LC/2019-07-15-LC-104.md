*Bài này áp dụng **Binary Tree DFS** từ [DSA Understanding – Part 18](/dsafundamental/2018/09/28/DSA-18.html).*

## 1. Đề bài đầy đủ

Cho `root` của binary tree. Trả về **độ sâu tối đa** — số **node** trên đường dài nhất từ root xuống leaf xa nhất.

## 2. Ví dụ minh hoạ

```
    3
   / \
  9  20
    /  \
   15   7
```
→ **3** (3 → 20 → 7)

## 3. Nhận diện pattern

+ Cây → **DFS đệ quy** chia left/right
+ Subproblem: depth cây con
+ Combine: `1 + max(left, right)`

## 4. Hướng tiếp cận từng bước

1. Base: `node is None` → 0
2. `return 1 + max(depth(left), depth(right))`
3. Hoặc BFS đếm số level

## 5. Code Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def maxDepth(root: TreeNode | None) -> int:
    if not root:
        return 0
    return 1 + max(maxDepth(root.left), maxDepth(root.right))
```

## 6. Trace (cây trên)

| Node | left depth | right depth | depth |
|------|------------|-------------|-------|
| 15,7 | 0 | 0 | 1 |
| 20 | 1 | 1 | 2 |
| 9 | 0 | - | 1 |
| 3 | 1 | 2 | **3** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**
+ **Space O(h)** recursion, h = height
