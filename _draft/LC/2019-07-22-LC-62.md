*Bài này áp dụng **2D Dynamic Programming** từ [DSA Understanding – Part 25](/dsafundamental/2018/11/16/DSA-25.html).*

## 1. Đề bài đầy đủ

Robot trên lưới `m × n`. Bắt đầu góc **trên-trái** `(0,0)`, chỉ di chuyển **phải** hoặc **xuống**. Trả về số **đường đi unique** tới góc **dưới-phải** `(m-1, n-1)`.

## 2. Ví dụ minh hoạ

| m | n | Output |
|---|---|--------|
| 3 | 7 | 28 |
| 3 | 2 | 3 |
| 7 | 3 | 28 |

Grid 3×2: R→R→D, R→D→R, D→R→R → 3 cách.

## 3. Nhận diện pattern

+ Đến `(i,j)` chỉ từ `(i-1,j)` hoặc `(i,j-1)` → **2D DP**
+ `dp[i][j] = dp[i-1][j] + dp[i][j-1]`
+ Base: hàng 0 và cột 0 = 1 (chỉ một cách đi thẳng)

## 4. Hướng tiếp cận từng bước

1. `dp[i][j]` = số đường tới `(i,j)`
2. Init row 0 và col 0 = 1
3. Fill `i=1..m-1`, `j=1..n-1`: cộng từ trên và trái
4. **Combinatorics**: C(m+n−2, m−1) — chọn vị trí các bước Down trong tổng m+n−2 bước

## 5. Code Python

```python
def uniquePaths(m: int, n: int) -> int:
    dp = [[1] * n for _ in range(m)]

    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

    return dp[m - 1][n - 1]
```

Space O(n) — một hàng:

```python
def uniquePaths(m: int, n: int) -> int:
    row = [1] * n

    for _ in range(1, m):
        for j in range(1, n):
            row[j] += row[j - 1]

    return row[n - 1]
```

## 6. Trace through m=3, n=2

```
    j=0  j=1
i=0  1    1
i=1  1    2  (1+1)
i=2  1    3  (1+2)
```

Answer: **3**

## 7. Phân tích độ phức tạp

+ **Time O(m × n)**
+ **Space O(n)** với rolling row, hoặc O(m×n) full table
