*Bài này áp dụng **Min Heap** từ [DSA Understanding – Part 22](/dsafundamental/2018/10/26/DSA-22.html).*

## 1. Đề bài đầy đủ

Thiết kế class `KthLargest`:

+ `KthLargest(k, nums)`: khởi tạo với k và mảng ban đầu
+ `add(val)`: thêm `val` vào stream, trả về **K-th largest** element hiện tại (1-based: largest = 1st largest)

## 2. Ví dụ minh hoạ

```
KthLargest(3, [4, 5, 8, 2])
add(3)  → 4   (stream [4,5,8,2,3], 3rd largest = 4)
add(5)  → 5
add(10) → 5
add(9)  → 8
add(4)  → 8
```

## 3. Nhận diện pattern

+ Cần **top K largest** liên tục khi stream grow → **min heap size K**
+ Root của min heap = phần tử **nhỏ nhất trong top K** = **K-th largest** toàn stream
+ Mỗi `add`: push, nếu size > K thì pop min

## 4. Hướng tiếp cận từng bước

1. Khởi tạo min heap, add tất cả nums ban đầu (pop nếu size > k)
2. `add(val)`:
   - `heappush(heap, val)`
   - Nếu `len(heap) > k`: `heappop(heap)` — loại phần tử nhỏ nhất
3. `getKthLargest()` = `heap[0]` (root min heap)

**Tại sao min heap?** Giữ K phần tử lớn nhất; phần tử nhỏ nhất trong nhóm đó chính là K-th largest.

## 5. Code Python

```python
import heapq


class KthLargest:
    def __init__(self, k: int, nums: list[int]):
        self.k = k
        self.heap: list[int] = []

        for num in nums:
            self.add(num)

    def add(self, val: int) -> int:
        heapq.heappush(self.heap, val)

        if len(self.heap) > self.k:
            heapq.heappop(self.heap)

        return self.heap[0]
```

## 6. Trace k=3, add(10) sau [4,5,8,2,3,5]

Heap trước add(10): giữ top 3 → `[4, 5, 8]` (min heap, root=4)

1. Push 10 → `[4, 5, 8, 10]`
2. Size 4 > 3 → pop min 4 → `[5, 8, 10]`
3. Return `heap[0]` = **5** — 3rd largest của stream

## 7. Phân tích độ phức tạp

+ **Init**: O(n log k) — n phần tử, mỗi add/pop O(log k)
+ **add**: O(log k) time, O(k) space
+ So với sort mỗi lần O(n log n) — heap hiệu quả hơn khi stream dài
