*Bài này áp dụng **sort + merge** từ [DSA Understanding – Part 11](/dsafundamental/2018/08/10/DSA-11.html).*

## 1. Đề bài đầy đủ

Cho mảng `intervals` với `intervals[i] = [start_i, end_i]`. Gộp mọi interval **chồng lấn** (overlap). Trả về mảng intervals **không overlap**, đã sort theo `start`.

## 2. Ví dụ minh hoạ

| intervals | Output |
|-----------|--------|
| [[1,3],[2,6],[8,10],[15,18]] | [[1,6],[8,10],[15,18]] |
| [[1,4],[4,5]] | [[1,5]] |
| [[1,4],[0,4]] | [[0,4]] |

## 3. Nhận diện pattern

+ Sau **sort theo start**, overlap ⇔ `current.end >= next.start`
+ Giống merge hai dãy sorted: một “dãy” kết quả, gộp khi trùng
+ Không sort → khó merge một pass

## 4. Hướng tiếp cận từng bước

1. `intervals.sort(key=lambda x: x[0])`
2. `merged = [intervals[0]]`
3. Duyệt `intervals[1:]`:
   - Nếu `interval[0] <= merged[-1][1]`: `merged[-1][1] = max(merged[-1][1], interval[1])`
   - Else: `merged.append(interval)`
4. Trả `merged`

## 5. Code Python

```python
def merge(intervals: list[list[int]]) -> list[list[int]]:
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_end = merged[-1][1]
        if start <= last_end:
            merged[-1][1] = max(last_end, end)
        else:
            merged.append([start, end])

    return merged
```

## 6. Trace [[1,3],[2,6],[8,10],[15,18]]

| Bước | merged |
|------|--------|
| init | [[1,3]] |
| [2,6] | 2≤3 → [[1,6]] |
| [8,10] | 8>6 → [[1,6],[8,10]] |
| [15,18] | append → **[[1,6],[8,10],[15,18]]** |

## 7. Phân tích độ phức tạp

+ **Time O(n log n)**: Sort dominates
+ **Space O(n)**: Output (hoặc O(log n) stack sort tùy implementation)

Duyệt linear sau sort O(n).

+ **Non-overlapping Intervals** (#435): Greedy, sort theo end
