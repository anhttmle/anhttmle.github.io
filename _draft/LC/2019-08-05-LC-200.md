*Bài này áp dụng **Matrix DFS/BFS** từ [DSA Understanding – Part 26](/dsafundamental/2018/11/23/DSA-26.html).*

## 1. Đề bài đầy đủ

Cho grid 2D `grid` gồm `'1'` (đất) và `'0'` (nước). Một **đảo** = vùng `'1'` liên thông **4 hướng** (không diagonal). Trả về **số đảo**.

## 2. Ví dụ minh hoạ

**Input:**
```
11110
11010
11000
00000
```
**Output:** 1

**Input:**
```
11000
11000
00100
00011
```
**Output:** 3

## 3. Nhận diện pattern

+ Grid graph → **connected components**
+ Gặp `'1'` chưa visit → count++, **flood fill** DFS/BFS đánh dấu cả component
+ Mỗi component = một đảo

## 4. Hướng tiếp cận từng bước

1. Duyệt mọi cell `(r, c)`
2. Nếu `grid[r][c] == '1'`:
   - `count += 1`
   - DFS/BFS: mark visited (đổi `'1'`→`'0'` hoặc visited set), explore 4 neighbors
3. Trả `count`

## 5. Code Python

```python
def numIslands(grid: list[list[str]]) -> int:
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r: int, c: int) -> None:
        if r < 0 or r >= rows or c < 0 or c >= cols:
            return
        if grid[r][c] != "1":
            return

        grid[r][c] = "0"  # mark visited

        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == "1":
                count += 1
                dfs(r, c)

    return count
```

## 6. Trace — grid 2×2 toàn '1'

1. (0,0)='1' → count=1, dfs flood 4 ô → all '0'
2. (0,1), (1,0), (1,1) đã '0' → skip
3. Return **1**

## 7. Phân tích độ phức tạp

+ **Time O(m × n)**: Mỗi cell visit tối đa 1 lần
+ **Space O(m × n)**: Recursion stack worst case (snake island)
