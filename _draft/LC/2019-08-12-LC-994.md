*Bài này áp dụng **Matrix BFS** từ [DSA Understanding – Part 26](/dsafundamental/2018/11/23/DSA-26.html).*

## 1. Đề bài đầy đủ

Grid: `0` = empty, `1` = fresh orange, `2` = rotten orange. Mỗi phút, rotten lan sang **fresh kề 4 hướng**. Trả về **số phút** để không còn fresh; nếu không thể → **-1**.

## 2. Ví dụ minh hoạ

**Input:**
```
2 1 1
1 1 0
0 1 1
```
**Output:** 4

**Input:** `[[2,1,1],[0,1,1],[1,0,1]]` → **-1** (góc dưới-trái fresh bị kẹt)

## 3. Nhận diện pattern

+ Lan theo **lớp đồng thời** → **Multi-source BFS**
+ Enqueue tất cả rotten ban đầu (distance 0)
+ Mỗi BFS level = 1 phút
+ Sau BFS: còn fresh → -1

## 4. Hướng tiếp cận từng bước

1. Queue chứa `(r, c)` mọi cell `= 2`, đếm `fresh`
2. BFS theo level:
   - Dequeue size lần = một phút
   - Neighbor fresh → rotten, fresh--, enqueue
   - `minutes++`
3. Nếu `fresh == 0` → return minutes; else -1

## 5. Code Python

```python
from collections import deque


def orangesRotting(grid: list[list[int]]) -> int:
    rows, cols = len(grid), len(grid[0])
    queue: deque[tuple[int, int]] = deque()
    fresh = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1

    minutes = 0
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

    while queue and fresh > 0:
        for _ in range(len(queue)):
            r, c = queue.popleft()

            for dr, dc in directions:
                nr, nc = r + dr, c + dc

                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))

        minutes += 1

    return minutes if fresh == 0 else -1
```

## 6. Trace — 1 fresh kề 1 rotten

1. Queue=[rotten], fresh=1
2. Level 0: lan sang fresh → fresh=0, minutes=1
3. Return **1**

## 7. Phân tích độ phức tạp

+ **Time O(m × n)**: Mỗi cell vào queue tối đa 1 lần
+ **Space O(m × n)**: Queue
