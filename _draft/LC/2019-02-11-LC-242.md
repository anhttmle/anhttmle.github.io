*Bài này áp dụng **frequency count với Hash Map** từ [DSA Understanding – Part 6](/dsafundamental/2018/07/06/DSA-06.html).*

## 1. Đề bài đầy đủ

Cho hai chuỗi `s` và `t`. Trả về `true` nếu `t` là **anagram** của `s` (cùng ký tự, khác thứ tự).

## 2. Ví dụ minh hoạ

| s | t | Output |
|---|---|--------|
| anagram | nagaram | true |
| rat | car | false |
| a | ab | false (khác độ dài) |

## 3. Nhận diện pattern

+ So sánh **tần suất ký tự** → frequency count
+ Hash Map hoặc array size 26 (chỉ chữ thường a-z)

## 4. Hướng tiếp cận

1. Nếu `len(s) != len(t)` → false
2. Đếm ký tự trong `s`: `count[c] += 1`
3. Duyệt `t`: `count[c] -= 1`. Nếu count < 0 → false
4. Hết vòng lặp → true (tổng count = 0)

**Tại sao đúng?** Anagram ⇔ mọi ký tự xuất hiện cùng số lần. Tăng từ s, giảm từ t — nếu khớp thì về 0.

## 5. Code Python

```python
def isAnagram(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False

    count = {}
    for c in s:
        count[c] = count.get(c, 0) + 1
    for c in t:
        if c not in count or count[c] == 0:
            return False
        count[c] -= 1

    return True
```

Hoặc: `return sorted(s) == sorted(t)` — O(n log n) nhưng ngắn.

## 6. Trace through s="anagram", t="nagaram"

Đếm s: {a:3, n:1, g:1, r:1, m:1}

Duyệt t: m(-1), a(2), g(0), a(1), r(0), a(0), n(0) — tất cả ≥ 0 → **true**

## 7. Phân tích độ phức tạp

+ **Time O(n)**: n = len(s), duyệt 2 lần
+ **Space O(1)**: Tối đa 26 ký tự trong map (constant)

## 8. Biến thể

+ Unicode / ký tự Unicode → dùng Counter hoặc map rộng hơn
+ **Group Anagrams** (#49): Nhiều chuỗi, nhóm theo anagram
