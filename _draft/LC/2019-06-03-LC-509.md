*Bài này áp dụng **Recursion & memoization** từ [DSA Understanding – Part 21](/dsafundamental/2018/10/19/DSA-21.html).*

## 1. Đề bài đầy đủ

Cho số nguyên `n`. Trả về **F(n)** — số Fibonacci thứ n, với:

+ F(0) = 0
+ F(1) = 1
+ F(n) = F(n−1) + F(n−2) với n > 1

## 2. Ví dụ minh hoạ

| n | Output | Giải thích |
|---|--------|------------|
| 2 | 1 | F(2) = F(1) + F(0) = 1 + 0 |
| 3 | 2 | 1 + 1 |
| 4 | 3 | 2 + 1 |

Dãy: 0, 1, 1, 2, 3, 5, 8, 13, …

## 3. Nhận diện pattern

+ Định nghĩa **đệ quy** sẵn → Recursion
+ Subproblem overlap (F(3) tính nhiều lần) → **Memoization** hoặc **bottom-up DP**
+ Tránh naive recursion O(2ⁿ) — LeetCode sẽ TLE

## 4. Hướng tiếp cận từng bước

**Bottom-up (khuyên dùng):**

1. `dp[0]=0`, `dp[1]=1`
2. Với `i` từ 2 đến n: `dp[i] = dp[i-1] + dp[i-2]`
3. Trả `dp[n]`

**Space O(1):** Chỉ giữ `prev, curr`, cập nhật mỗi bước.

## 5. Code Python

```python
def fib(n: int) -> int:
    if n <= 1:
        return n

    prev, curr = 0, 1
    for _ in range(2, n + 1):
        prev, curr = curr, prev + curr

    return curr
```

Memoization:

```python
def fib(n: int) -> int:
    memo = {0: 0, 1: 1}

    def helper(k: int) -> int:
        if k in memo:
            return memo[k]
        memo[k] = helper(k - 1) + helper(k - 2)
        return memo[k]

    return helper(n)
```

## 6. Trace through n=5

| i | prev | curr | Sau loop |
|---|------|------|----------|
| init | 0 | 1 | — |
| 2 | 1 | 1 | curr=1 |
| 3 | 1 | 2 | |
| 4 | 2 | 3 | |
| 5 | 3 | **5** | return 5 |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Tính từ 2 đến n, mỗi bước O(1)
+ **Space O(1)**: Hai biến (bottom-up optimized)
+ Naive recursion: O(2ⁿ) time, O(n) stack — **tránh**

## 8. Biến thể

+ **Climbing Stairs** (#70): Cùng công thức, base case khác (dp[0]=1)
+ **N-th Tribonacci** (#1137): Ba số trước thay vì hai
+ Matrix exponentiation: O(log n) cho n rất lớn
