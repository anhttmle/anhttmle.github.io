*Bài này áp dụng **Backtracking** từ [DSA Understanding – Part 23](/dsafundamental/2018/11/02/DSA-23.html).*

## 1. Đề bài đầy đủ

Cho mảng `nums` gồm **các phần tử distinct**. Trả về **tất cả subsets** (power set). Thứ tự subset và phần tử không quan trọng.

## 2. Ví dụ minh hoạ

**Input:** `[1, 2, 3]`

**Output:** `[[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]`

2³ = 8 subsets.

## 3. Nhận diện pattern

+ Mỗi phần tử: **chọn hoặc không chọn** → Backtracking
+ Hoặc: tại index `start`, thử pick `nums[i]` rồi recurse `i+1`
+ **Không cần undo path** nếu copy khi record — hoặc append/pop in-place

## 4. Hướng tiếp cận từng bước

1. `result = []`, `path = []`
2. `backtrack(start)`:
   - Append copy của `path` vào `result` (mọi node đều là subset hợp lệ)
   - For `i` from `start` to `n-1`:
     - `path.append(nums[i])`
     - `backtrack(i + 1)`
     - `path.pop()` — undo

**Tại sao start index?** Tránh duplicate như `[2,1]` khi đã có `[1,2]`.

## 5. Code Python

```python
def subsets(nums: list[int]) -> list[list[int]]:
    result: list[list[int]] = []
    path: list[int] = []

    def backtrack(start: int) -> None:
        result.append(path[:])

        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return result
```

Iterative (bitmask): duyệt mask 0..2^n-1.

## 6. Trace through [1, 2]

| start | path | result thêm |
|-------|------|-------------|
| 0 | [] | [] |
| pick 1 | [1] | [1] |
| pick 2 | [1,2] | [1,2] |
| back, pick 2 | [2] | [2] |

## 7. Phân tích độ phức tạp

+ **Time O(n × 2ⁿ)**: 2ⁿ subsets, mỗi subset copy O(n) worst
+ **Space O(n)**: Recursion depth + path (không tính output)

## 8. Biến thể

+ **Subsets II** (#90): Có duplicate — sort + skip same level
+ **Combinations** (#77): Chỉ subset size k
+ **Permutations** (#46): Mọi thứ tự — dùng `used[]` thay start index
