Chào các bạn, muốn “ghé thăm” mọi phòng trong tòa nhà có hai nhánh mỗi tầng — bạn có thể đi **sâu** hết một nhánh rồi quay lại (**DFS**), hoặc duyệt **từng tầng** từ lobby (**BFS**). Cây nhị phân cũng có hai kiểu duyệt tương ứng.

## 1. Intuition

**DFS (Depth-First):** Đi xuống sâu nhất trước, rồi backtrack.

+ **Pre-order:** root → left → right (copy cây, prefix)
+ **In-order:** left → root → right (BST → sorted)
+ **Post-order:** left → right → root (xóa cây, tính diameter)

**BFS (Breadth-First):** Hàng đợi — xử lý tầng 0, rồi tầng 1, … Dùng cho **level order**, shortest path trên cây không trọng số.

## 2. Cách hoạt động — từng bước

**DFS iterative (pre-order):**

1. Push root vào stack
2. Pop node, xử lý, push right rồi left (để left pop trước)

**BFS level order:**

1. Queue `[root]`
2. Khi queue không rỗng: `size = len(queue)`, lấy đúng `size` node = một level, enqueue con không null

## 3. Tại sao giải thuật này đúng?

Mỗi node được **enqueue/push đúng một lần** (với visited logic trên graph; trên tree không cycle). DFS thăm toàn bộ nhánh trước khi backtrack → mọi node được visit.

**BFS level:** Mọi node depth d vào queue sau khi depth d−1 xử lý xong → thứ tự theo level đúng.

## 4. Phân tích độ phức tạp

| | DFS | BFS |
|---|-----|-----|
| Time | O(n) | O(n) |
| Space | O(h) stack | O(w) queue, w = max width |

Cây cân bằng: h = log n, w ≈ n/2 ở tầng cuối.

## Common Mistakes: Tree Traversal

- **DFS stack overflow:** Cây skewed sâu — dùng iterative hoặc tăng stack limit.
- **BFS enqueue null:** Chỉ add `node.left` / `node.right` khi khác null.
- **Level order:** Quên cố định `size` trước vòng trong — lẫn level.
- **In-order trên non-BST:** Không ra sorted order.
