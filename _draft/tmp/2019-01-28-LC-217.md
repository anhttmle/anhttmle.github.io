*Bài này áp dụng **Hash Set** từ [DSA Understanding – Part 5](/dsafundamental/2018/06/29/DSA-05.html).*

## 1. Đề bài đầy đủ

Cho mảng số nguyên `nums`. Trả về `true` nếu **có ít nhất một giá trị xuất hiện từ 2 lần trở lên**, ngược lại `false`.

## 2. Ví dụ minh hoạ

| nums | Output |
|------|--------|
| [1, 2, 3, 1] | true (1 lặp) |
| [1, 2, 3, 4] | false |
| [1, 1, 1, 3, 3, 4, 3, 2, 4, 2] | true |

## 3. Nhận diện pattern

+ Cần check **tồn tại / trùng lặp** → **Hash Set**
+ Chỉ cần biết "đã thấy chưa" — không cần value → Set đủ, không cần Map

## 4. Hướng tiếp cận

1. Tạo set rỗng `seen`
2. Duyệt từng `num`:
   - Nếu `num in seen` → return `true`
   - `seen.add(num)`
3. Hết vòng lặp → return `false`

**Cách khác:** Sort rồi so sánh liền kề — O(n log n). Hash Set O(n) nhanh hơn.

## 5. Code Python

```python
def containsDuplicate(nums: list[int]) -> bool:
    seen = set()
    for num in nums:
        if num in seen:
            return True
        seen.add(num)
    return False
```

Hoặc ngắn gọn: `return len(nums) != len(set(nums))`

## 6. Trace through [1, 2, 3, 1]

| num | seen trước | Hành động |
|-----|------------|-----------|
| 1 | {} | add → {1} |
| 2 | {1} | add → {1,2} |
| 3 | {1,2} | add → {1,2,3} |
| 1 | {1,2,3} | 1 in seen → **true** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Duyệt 1 lần, set ops O(1) average
+ **Space O(n)**: Set lưu tối đa n phần tử
