*Bài này áp dụng **1D Dynamic Programming** từ [DSA Understanding – Part 24](/dsafundamental/2018/11/09/DSA-24.html).*

## 1. Đề bài đầy đủ

Có `n` bậc thang. Mỗi lần leo **1 hoặc 2** bậc. Trả về **số cách** leo hết `n` bậc.

## 2. Ví dụ minh hoạ

| n | Output | Giải thích |
|---|--------|------------|
| 2 | 2 | 1+1 hoặc 2 |
| 3 | 3 | 1+1+1, 1+2, 2+1 |
| 4 | 5 | Fibonacci-like |

## 3. Nhận diện pattern

+ Bước cuối 1 hoặc 2 bậc → `ways(n) = ways(n-1) + ways(n-2)`
+ **Giống Fibonacci** — base case khác: `dp[0]=1`, `dp[1]=1` (hoặc dp[1]=1, dp[2]=2)
+ Overlapping subproblems → DP, không naive recursion

## 4. Hướng tiếp cận từng bước

1. `dp[i]` = số cách leo tới bậc i
2. Base: `dp[1]=1`, `dp[2]=2` (hoặc dp[0]=1, dp[1]=1)
3. Transition: `dp[i] = dp[i-1] + dp[i-2]`
4. Space O(1): `prev, curr` thay array

## 5. Code Python

```python
def climbStairs(n: int) -> int:
    if n <= 2:
        return n

    prev, curr = 1, 2
    for _ in range(3, n + 1):
        prev, curr = curr, prev + curr

    return curr
```

Bottom-up array:

```python
def climbStairs(n: int) -> int:
    if n <= 2:
        return n

    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2

    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]
```

## 6. Trace through n=5

| i | dp[i-1] | dp[i-2] | dp[i] |
|---|---------|---------|-------|
| 3 | 2 | 1 | 3 |
| 4 | 3 | 2 | 5 |
| 5 | 5 | 3 | **8** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**
+ **Space O(1)** với hai biến

## 8. Biến thể

+ **Min Cost Climbing Stairs** (#746): Cộng cost, chọn min
+ **Fibonacci Number** (#509): Cùng recurrence, base khác
+ **Climbing Stairs với 1,2,3 bước**: dp[i] = dp[i-1]+dp[i-2]+dp[i-3]
