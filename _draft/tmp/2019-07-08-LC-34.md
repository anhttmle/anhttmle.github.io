*Bài này áp dụng **Lower / Upper Bound** từ [DSA Understanding – Part 17](/dsafundamental/2018/09/21/DSA-17.html).*

## 1. Đề bài đầy đủ

Cho `nums` sort (có thể trùng) và `target`. Trả về `[first, last]` index của `target`, hoặc `[-1, -1]` nếu không có. Yêu cầu **O(log n)**.

## 2. Ví dụ minh hoạ

| nums | target | Output |
|------|--------|--------|
| [5,7,7,8,8,10] | 8 | [3, 4] |
| [5,7,7,8,8,10] | 6 | [-1, -1] |
| [] | 0 | [-1, -1] |

## 3. Nhận diện pattern

+ Duplicate trên sorted → BS chuẩn không đủ
+ **First** = lower bound(`target`)
+ **Last** = upper bound(`target`) - 1

## 4. Hướng tiếp cận từng bước

1. `left_bound(target)`: first index với `nums[i] >= target`
2. Nếu `left == n` hoặc `nums[left] != target` → [-1,-1]
3. `right_bound(target)`: first index với `nums[i] > target`, last = right - 1

## 5. Code Python

```python
def searchRange(nums: list[int], target: int) -> list[int]:
    def lower_bound(x: int) -> int:
        lo, hi = 0, len(nums)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if nums[mid] < x:
                lo = mid + 1
            else:
                hi = mid
        return lo

    def upper_bound(x: int) -> int:
        lo, hi = 0, len(nums)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            if nums[mid] <= x:
                lo = mid + 1
            else:
                hi = mid
        return lo

    first = lower_bound(target)
    if first == len(nums) or nums[first] != target:
        return [-1, -1]
    last = upper_bound(target) - 1
    return [first, last]
```

## 6. Trace nums=[5,7,7,8,8,10], target=8

+ lower_bound(8) → index **3**
+ upper_bound(8) → index **5** → last = 4
+ **[3, 4]**

## 7. Phân tích độ phức tạp

+ **Time O(log n)** — hai lần BS
+ **Space O(1)**
