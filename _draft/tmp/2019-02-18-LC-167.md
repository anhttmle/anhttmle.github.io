*Bài này áp dụng **Two Pointer – Opposite Direction** từ [DSA Understanding – Part 7](/dsafundamental/2018/07/13/DSA-07.html).*

## 1. Đề bài đầy đủ

Cho mảng số nguyên `numbers` **đã sort tăng dần** (1-indexed trong đề) và `target`. Trả về **hai index** (1-based) `i`, `j` sao cho `numbers[i] + numbers[j] == target`.

Giả sử có **đúng một** cặp nghiệm, và không dùng cùng phần tử hai lần.

## 2. Ví dụ minh hoạ

| numbers | target | Output | Giải thích |
|---------|--------|--------|------------|
| [2, 7, 11, 15] | 9 | [1, 2] | 2 + 7 = 9 |
| [2, 3, 4] | 6 | [1, 3] | 2 + 4 = 6 |
| [-1, 0] | -1 | [1, 2] | -1 + 0 = -1 |

## 3. Nhận diện pattern

+ Mảng **sorted** + tìm cặp tổng = target → **opposite two pointer**
+ Khác #1: không cần Hash Map vì thứ tự cho phép loại bỏ nửa không gian mỗi bước
+ Output **1-based** → trả `left+1`, `right+1`

## 4. Hướng tiếp cận từng bước

1. `left = 0`, `right = len(numbers) - 1`
2. `s = numbers[left] + numbers[right]`
3. `s == target` → return `[left+1, right+1]`
4. `s > target` → `right--` (cần tổng nhỏ hơn)
5. `s < target` → `left++`

## 5. Code Python

```python
def twoSum(numbers: list[int], target: int) -> list[int]:
    left, right = 0, len(numbers) - 1

    while left < right:
        total = numbers[left] + numbers[right]
        if total == target:
            return [left + 1, right + 1]
        if total > target:
            right -= 1
        else:
            left += 1

    return []
```

## 6. Trace through numbers=[2,7,11,15], target=9

| left | right | total | Hành động |
|------|-------|-------|-----------|
| 0 | 3 | 17 | > 9 → right-- |
| 0 | 2 | 13 | > 9 → right-- |
| 0 | 1 | 9 | == 9 → **return [1, 2]** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Mỗi pointer di chuyển tối đa n lần
+ **Space O(1)**: Chỉ hai index

## 8. Biến thể

+ **Two Sum** (#1): Unsorted → Hash Map
+ **3Sum** (#15): Cố định i + two pointer trên phần còn lại
+ **4Sum** (#18): Mở rộng tương tự
