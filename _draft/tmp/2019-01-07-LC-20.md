*Bài này áp dụng **Stack** từ [DSA Understanding – Part 4: Stack & Queue](/dsafundamental/2018/06/22/DSA-04.html).*

## 1. Đề bài đầy đủ

Cho chuỗi `s` chỉ gồm các ký tự `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'`.

Trả về `true` nếu chuỗi **hợp lệ**:
+ Mỗi ngoặc mở phải được đóng bởi cùng loại ngoặc
+ Ngoặc đóng đúng **thứ tự** (LIFO)

## 2. Ví dụ minh hoạ

| Input | Output | Giải thích |
|-------|--------|------------|
| `"()"` | true | Mở rồi đóng đúng |
| `"()[]{}"` | true | Ba cặp độc lập |
| `"(]"` | false | `(` mở nhưng `]` đóng — sai loại |
| `"([)]"` | false | `[` chưa đóng đã gặp `)` |
| `"{[]}"` | true | Lồng nhau đúng thứ tự |

## 3. Nhận diện pattern

+ Cần **khớp cặp** theo thứ tự **lồng nhau gần nhất trước** → **LIFO** → **Stack**
+ Gặp ngoặc mở → push
+ Gặp ngoặc đóng → pop và kiểm tra khớp

## 4. Hướng tiếp cận từng bước

1. Tạo stack rỗng và map đóng → mở: `')'→'('`, `'}'→'{'`, `']'→'['`
2. Duyệt từng ký tự `c` trong `s`:
   - Nếu `c` là ngoặc mở → push vào stack
   - Nếu `c` là ngoặc đóng:
     - Stack rỗng → false
     - Pop top, so với map — không khớp → false
3. Sau vòng lặp: stack rỗng → true (không còn ngoặc mở thừa)

## 5. Code Python

```python
def isValid(s: str) -> bool:
    stack = []
    pairs = {')': '(', '}': '{', ']': '['}

    for c in s:
        if c in pairs:          # ngoặc đóng
            if not stack or stack[-1] != pairs[c]:
                return False
            stack.pop()
        else:                   # ngoặc mở
            stack.append(c)

    return len(stack) == 0
```

## 6. Trace through `"({[]})"`

| Bước | c | Stack sau | Ghi chú |
|------|---|-----------|---------|
| 1 | `(` | `[(` | push |
| 2 | `{` | `[(, {]` | push |
| 3 | `[` | `[(, {, []` | push |
| 4 | `]` | `[(, {]` | pop, khớp `[` |
| 5 | `}` | `[(]` | pop, khớp `{` |
| 6 | `)` | `[]` | pop, khớp `(` |
| 7 | end | `[]` | rỗng → **true** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Duyệt mỗi ký tự 1 lần, push/pop O(1)
+ **Space O(n)**: Worst case toàn ngoặc mở, vd: `"((("` 

## 8. Biến thể & follow-up

+ Chuỗi có thêm ký tự khác → bỏ qua hoặc xử lý riêng
+ Tìm **vị trí** ngoặc sai đầu tiên → lưu index khi fail
+ **Minimum Add to Make Valid** — đếm ngoặc thiếu
