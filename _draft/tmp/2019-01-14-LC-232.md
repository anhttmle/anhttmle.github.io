## 1. Đề bài đầy đủ

Implement hàng đợi **FIFO** chỉ dùng hai **Stack** (LIFO). Class `MyQueue` hỗ trợ:
+ `push(x)` — thêm phần tử vào cuối queue
+ `pop()` — lấy phần tử ở đầu queue
+ `peek()` — xem phần tử đầu
+ `empty()` — queue có rỗng không

## 2. Ví dụ minh hoạ

```
push(1) → queue: [1]
push(2) → queue: [1, 2]
peek()  → 1
pop()   → 1, queue: [2]
empty() → false
```

## 3. Nhận diện pattern

+ Stack đảo thứ tự — cần **hai stack** để "hoàn tác" thứ tự
+ **stack_in**: nhận push
+ **stack_out**: phục vụ pop/peek — khi rỗng, chuyển hết stack_in sang

## 4. Hướng tiếp cận từng bước

1. `push(x)`: push x vào `stack_in`
2. `pop()` / `peek()`:
   - Nếu `stack_out` rỗng → pop hết `stack_in` sang `stack_out` (đảo thứ tự)
   - Pop/peek từ `stack_out` (phần tử "cũ nhất" nằm top stack_out)

**Tại sao đúng?** Phần tử push đầu tiên nằm đáy stack_in. Khi chuyển sang stack_out, nó lên top → pop ra đúng FIFO.

## 5. Code Python

```python
class MyQueue:
    def __init__(self):
        self.stack_in = []
        self.stack_out = []

    def push(self, x: int) -> None:
        self.stack_in.append(x)

    def _pour(self) -> None:
        if not self.stack_out:
            while self.stack_in:
                self.stack_out.append(self.stack_in.pop())

    def pop(self) -> int:
        self._pour()
        return self.stack_out.pop()

    def peek(self) -> int:
        self._pour()
        return self.stack_out[-1]

    def empty(self) -> bool:
        return not self.stack_in and not self.stack_out
```

## 7. Phân tích độ phức tạp

+ **push**: O(1)
+ **pop/peek**: O(1) amortized (mỗi phần tử chuyển stack tối đa 1 lần)
+ **Space**: O(n)
