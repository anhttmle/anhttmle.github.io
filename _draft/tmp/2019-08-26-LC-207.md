*Bài này áp dụng **Adjacency List + cycle detection** từ [DSA Understanding – Part 27](/dsafundamental/2018/11/30/DSA-27.html) — bài LeetCode Practice cuối cùng đi kèm series DSA Understanding.*

## 1. Đề bài đầy đủ

Có `numCourses` khóa học labeled `0 .. numCourses-1`. `prerequisites[i] = [a, b]` nghĩa: muốn học **a** phải học **b** trước (edge **b → a**).

Trả về `true` nếu có thể hoàn thành **tất cả** khóa; `false` nếu **cycle** trong dependency graph.

## 2. Ví dụ minh hoạ

| numCourses | prerequisites | Output |
|------------|---------------|--------|
| 2 | [[1,0]] | true | 0 rồi 1 |
| 2 | [[1,0],[0,1]] | false | cycle 0↔1 |
| 4 | [[1,0],[2,0],[3,1],[3,2]] | true | DAG |

## 3. Nhận diện pattern

+ **Directed graph** — edge b→a
+ Hoàn thành tất cả ⟺ graph **DAG** (không cycle)
+ **Kahn's algorithm** (BFS in-degree) hoặc **DFS 3-color** cycle detect

## 4. Hướng tiếp cận từng bước

**Kahn BFS:**

1. Build adj list + `in_degree[v]` = số prerequisite của v
2. Queue mọi course `in_degree == 0`
3. While queue: dequeue u, `count++`, giảm in_degree neighbors; nếu 0 → enqueue
4. `count == numCourses` → true (không cycle)

**DFS 3-color:** white=chưa visit, gray=đang trong stack, black=xong. Gặp gray neighbor → cycle.

## 5. Code Python

Kahn BFS:

```python
from collections import deque


def canFinish(numCourses: int, prerequisites: list[list[int]]) -> bool:
    adj: list[list[int]] = [[] for _ in range(numCourses)]
    in_degree = [0] * numCourses

    for course, prereq in prerequisites:
        adj[prereq].append(course)
        in_degree[course] += 1

    queue: deque[int] = deque(
        i for i in range(numCourses) if in_degree[i] == 0
    )
    finished = 0

    while queue:
        u = queue.popleft()
        finished += 1

        for v in adj[u]:
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)

    return finished == numCourses
```

## 6. Trace — [[1,0],[0,1]]

+ Edges: 0→1, 1→0
+ in_degree: [1, 1] — không course nào = 0
+ Queue rỗng → finished=0 ≠ 2 → **false**

## 7. Phân tích độ phức tạp

+ **Time O(V + E)**: V = numCourses, E = len(prerequisites)
+ **Space O(V + E)**: Adj list + in_degree + queue
