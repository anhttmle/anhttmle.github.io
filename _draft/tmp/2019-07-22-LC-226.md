*Bài này áp dụng **Binary Tree traversal** từ [DSA Understanding – Part 18](/dsafundamental/2018/09/28/DSA-18.html).*

## 1. Đề bài đầy đủ

Cho `root` binary tree. **Đảo** (mirror): hoán đổi `left` và `right` của **mọi** node. Trả về `root`.

## 2. Ví dụ minh hoạ

| Input | Output |
|-------|--------|
| [4,2,7,1,3,6,9] | [4,7,2,9,6,3,1] |
| [2,1,3] | [2,3,1] |
| [] | [] |

## 3. Nhận diện pattern

+ Transform cây → DFS pre-order: **swap** tại node, rồi đệ quy con
+ Hoặc BFS: swap khi dequeue

## 4. Hướng tiếp cận từng bước

1. Nếu `root` null → return
2. `root.left, root.right = root.right, root.left`
3. `invertTree(root.left)`, `invertTree(root.right)`
4. Return `root`

## 5. Code Python

```python
def invertTree(root: TreeNode | None) -> TreeNode | None:
    if not root:
        return None
    root.left, root.right = root.right, root.left
    invertTree(root.left)
    invertTree(root.right)
    return root
```

## 6. Trace node 4 (subtree 2,7)

+ Swap → left=7, right=2
+ Đệ quy invert 7 và 2 (swap con của chúng)
+ Cả cây mirror hoàn tất

## 7. Phân tích độ phức tạp

+ **Time O(n)** — visit mỗi node một lần
+ **Space O(h)** stack

## 8. Biến thể

+ **#101** Symmetric Tree (so sánh mirror)
+ **#100** Same Tree
+ **#617** Merge Two Binary Trees
