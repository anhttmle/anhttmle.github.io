Chào các bạn, bệnh viện có hàng đợi cấp cứu: bệnh nhân nặng nhất được xử lý trước, không phải ai đến trước. **Heap** (cụ thể **Priority Queue**) mô phỏng chính logic đó — luôn lấy phần tử **ưu tiên nhất** trong O(log n).

## 1. Intuition

Tưởng tượng một **hàng đợi ưu tiên** tại quầy vé máy bay: hạng Business luôn được gọi trước Economy, bất kể ai xếp hàng trước.

**Binary Heap** là cây nhị phân **complete** thỏa **heap property**:

+ **Min Heap**: parent ≤ mọi children → root là **minimum**
+ **Max Heap**: parent ≥ mọi children → root là **maximum**

Không cần sort toàn bộ — chỉ cần biết ai đứng đầu hàng.

## 2. Cách hoạt động — từng bước

Heap lưu bằng **array**: node tại index `i` có children tại `2i+1` và `2i+2`, parent tại `(i-1)//2`.

**Push (insert):**

1. Thêm phần tử vào cuối array
2. **Bubble up** (sift up): swap với parent nếu vi phạm heap property
3. Lặp đến khi đúng property hoặc chạm root

**Pop (extract min/max):**

1. Lưu giá trị root (min hoặc max)
2. Move phần tử cuối lên root, xóa phần tử cuối
3. **Bubble down** (sift down): swap với child nhỏ hơn (min heap) hoặc lớn hơn (max heap)
4. Lặp đến khi heap property khôi phục

**Trace push 3 vào min heap [1, 5, 4]:**

1. Thêm 3 → `[1, 5, 4, 3]`
2. 3 < parent 5 → swap → `[1, 3, 4, 5]`
3. 3 > parent 1 → dừng. Root vẫn là 1 ✓

## 3. Tại sao giải thuật này đúng?

**Heap property invariant:** Sau mỗi push/pop, mọi node đều ≤ (min heap) hoặc ≥ (max heap) con của nó.

Bubble up chỉ di chuyển phần tử **lên đúng vị trí** — không phá property của subtree khác. Bubble down tương tự xuống dưới.

Vì cây **complete**, chiều cao = O(log n) → mỗi push/pop tối đa O(log n) swap.

## 4. Phân tích độ phức tạp

| Thao tác | Time | Ghi chú |
|----------|------|---------|
| Push | O(log n) | Bubble up tối đa h height |
| Pop | O(log n) | Bubble down tối đa h height |
| Peek (xem root) | O(1) | Không thay đổi heap |
| Build heap từ array | O(n) | Heapify bottom-up |

**Use cases:** Dijkstra, task scheduling, **Top K elements**, Merge K sorted lists, Heap Sort O(n log n).

## Common Mistakes: Heap

- **Nhầm min/max heap**: Top K **largest** dùng **min heap** size k; Top K **smallest** dùng **max heap** size k.
- **Index formula sai**: Parent of `i` = `(i-1)//2`, không phải `i//2`.
- **Heap vs BST**: Heap chỉ guarantee root min/max — không sorted toàn bộ.
- **Quên heapify sau build**: `heapq.heapify()` trong Python biến list thành min heap O(n).
