*Bài này áp dụng **DFS Post-order** từ [DSA Understanding – Part 20](/dsafundamental/2018/10/12/DSA-20.html).*

## 1. Đề bài đầy đủ

Cho `root` binary tree. **Diameter** = độ dài đường đi dài nhất giữa hai node (số **cạnh**). Đường có thể không qua root.

## 2. Ví dụ minh hoạ

```
      1
     / \
    2   3
   / \
  4   5
```
Diameter = **3** (path 4–2–1–3 hoặc 5–2–1–3).

## 3. Nhận diện pattern

+ Tại mỗi node, đường dài nhất **qua node** = depth(left) + depth(right)
+ **Post-order:** tính depth con trước, cập nhật global max diameter
+ Không nhầm với height của cây

## 4. Hướng tiếp cận từng bước

1. Biến global `best = 0`
2. Hàm `depth(node)` trả chiều cao (số cạnh) subtree
3. Tại node: `best = max(best, depth(left) + depth(right))`
4. Return `1 + max(left_depth, right_depth)`
5. Trả `best`

## 5. Code Python

```python
def diameterOfBinaryTree(root: TreeNode | None) -> int:
    best = 0

    def depth(node: TreeNode | None) -> int:
        nonlocal best
        if not node:
            return 0
        left_d = depth(node.left)
        right_d = depth(node.right)
        best = max(best, left_d + right_d)
        return 1 + max(left_d, right_d)

    depth(root)
    return best
```

## 6. Trace (cây trên)

| Node | left_d | right_d | qua node | best |
|------|--------|---------|----------|------|
| 4,5 | 0 | 0 | 0 | 0 |
| 2 | 1 | 1 | 2 | 2 |
| 3 | 0 | 0 | 0 | 2 |
| 1 | 2 | 1 | **3** | **3** |

## 7. Phân tích độ phức tạp

+ **Time O(n)**
+ **Space O(h)** recursion
