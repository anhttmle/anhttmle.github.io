*Bài này áp dụng **Read/Write pointer (same direction)** từ [DSA Understanding – Part 8](/dsafundamental/2018/07/20/DSA-08.html).*

## 1. Đề bài đầy đủ

Cho mảng số nguyên `nums`. Di chuyển **tất cả số 0** về **cuối** mảng, giữ **thứ tự tương đối** của phần tử khác 0. Thực hiện **in-place**, không copy mảng mới.

## 2. Ví dụ minh hoạ

| nums (trước) | nums (sau) |
|--------------|------------|
| [0,1,0,3,12] | [1,3,12,0,0] |
| [0] | [0] |
| [1,0,2] | [1,2,0] |

## 3. Nhận diện pattern

+ Gom phần tử “cần giữ” về trước → **write pointer**
+ `read` quét toàn mảng; non-zero ghi vào `write` rồi tăng `write`
+ Cuối fill 0 từ `write` đến hết (hoặc swap variant)

## 4. Hướng tiếp cận từng bước

1. `write = 0`
2. `for read in range(len(nums))`:
   - Nếu `nums[read] != 0`: `nums[write] = nums[read]`, `write += 1`
3. `for i in range(write, len(nums))`: `nums[i] = 0`

**Invariant:** `nums[0..write-1]` chứa mọi non-zero đã gặp, đúng thứ tự.

## 5. Code Python

```python
def moveZeroes(nums: list[int]) -> None:
    write = 0

    for read in range(len(nums)):
        if nums[read] != 0:
            nums[write] = nums[read]
            write += 1

    for i in range(write, len(nums)):
        nums[i] = 0
```

## 6. Trace through nums=[0,1,0,3,12]

| read | nums[read] | write sau | nums (non-zero prefix) |
|------|------------|-----------|------------------------|
| 0 | 0 | 0 | |
| 1 | 1 | 1 | [1,...] |
| 2 | 0 | 1 | |
| 3 | 3 | 2 | [1,3,...] |
| 4 | 12 | 3 | [1,3,12,...] |
| fill | | | [1,3,12,0,0] |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Hai pass tuyến tính
+ **Space O(1)**: In-place

Swap variant (một pass, đẩy 0 sang phải khi gặp) cũng O(n) — tối đa n swap.

## 8. Biến thể

+ **Remove Element** (#27): Gom phần tử ≠ val, không cần fill
+ **Remove Duplicates from Sorted Array** (#26): write chỉ tăng khi khác phần tử trước
+ **Sort Colors** (#75): Dutch national flag — ba loại 0,1,2
