*Bài này áp dụng **BST Insert** từ [DSA Understanding – Part 19](/dsafundamental/2018/10/05/DSA-19.html).*

## 1. Đề bài đầy đủ

Cho `root` BST và `val`. **Chèn** `val` theo BST property, trả về root cây (có thể thay đổi nếu cây rỗng).

## 2. Ví dụ minh hoạ

```
    4
   / \
  2   7
 / \
1   3
```
Insert `5` → 5 là con trái của 7.

## 3. Nhận diện pattern

+ Đi như search đến `null`, gắn `TreeNode(val)`
+ Đệ quy hoặc iterative một con trỏ `cur`

## 4. Hướng tiếp cận từng bước

**Recursive:**

1. Không root → `TreeNode(val)`
2. `val < root.val` → `root.left = insert(left)`
3. `val > root.val` → `root.right = insert(right)`
4. Return `root`

## 5. Code Python

```python
def insertIntoBST(
    root: TreeNode | None, val: int
) -> TreeNode | None:
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = insertIntoBST(root.left, val)
    else:
        root.right = insertIntoBST(root.right, val)
    return root
```

## 6. Trace insert 5 vào cây trên

| cur | So sánh | Tiếp |
|-----|---------|------|
| 4 | 5 > 4 | right |
| 7 | 5 < 7 | left |
| null | gắn node 5 dưới 7.left |

## 7. Phân tích độ phức tạp

+ **Time O(h)**
+ **Space O(h)** recursion
