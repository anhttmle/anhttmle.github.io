Chào các bạn, sơ đồ tổ chức công ty: một CEO, mỗi người tối đa hai cấp dưới trực tiếp — đó là hình ảnh **binary tree**. Không phải graph tùy ý: có **gốc**, không **cycle**, mỗi node tối đa **hai con**.

## 1. Intuition

**Binary Tree:** Mỗi node có `left` và `right` (có thể `null`). Node không con = **leaf**.

+ **Root:** Gốc — điểm bắt đầu mọi duyệt
+ **Depth:** Số cạnh từ root tới node (root depth 0)
+ **Height:** Độ sâu max từ node xuống leaf (leaf height 0 theo convention LeetCode)

**Tree vs Graph:** Tree connected, acyclic, n node có đúng n−1 cạnh. Graph có thể cycle, nhiều cha.

## 2. Cách hoạt động — từng bước

**Biểu diễn (LeetCode):**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

**Duyệt recursive — pattern chung:**

1. Base: `if not node: return` (giá trị mặc định)
2. Xử lý node (tùy pre/in/post order)
3. Gọi đệ quy `left`, `right`

{% include dsa18-binary-tree-demo.html %}

**Ví dụ depth (max depth):** `1 + max(depth(left), depth(right))` — mỗi node tính một lần → O(n).

## 3. Tại sao giải thuật này đúng?

Đệ quy trên tree = chia bài toán trên cây con. Vì không cycle, mỗi nhánh độc lập, độ sâu đệ quy = height h → stack O(h).

**Structural induction:** Kết quả đúng trên cây con → ghép tại node cha → đúng cả cây.

## 4. Phân tích độ phức tạp

+ Visit mỗi node một lần: **Time O(n)**
+ **Space O(h)** recursion (h = height); skewed tree h = n → worst O(n)

## Common Mistakes: Binary Tree

- **Quên null:** Luôn `if not node: return` trước khi đọc `node.left`.
- **Nhầm height và depth:** LeetCode depth thường = số node trên path (104).
- **Single node:** Depth = 1 (chỉ root) theo đề 104 — đọc kỹ convention.
- **In-order sorted:** Chỉ đúng khi cây là **BST**, không phải binary tree bất kỳ.
