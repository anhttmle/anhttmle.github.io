*Bài này áp dụng **Quickselect / partition** từ [DSA Understanding – Part 12](/dsafundamental/2018/08/17/DSA-12.html).*

## 1. Đề bài đầy đủ

Cho mảng số nguyên `nums` **không rỗng** và số nguyên `k` (1 ≤ k ≤ size). Trả về phần tử **lớn thứ k** trong mảng (không nhất thiết distinct).

Ví dụ: `[3,2,1,5,6,4]`, k=2 → `5` (thứ hai lớn nhất).

## 2. Ví dụ minh hoạ

| nums | k | Output |
|------|---|--------|
| [3,2,1,5,6,4] | 2 | 5 |
| [3,2,3,1,2,4,5,5,6] | 4 | 4 |
| [1] | 1 | 1 |

## 3. Nhận diện pattern

+ Top-k / kth largest → **Quickselect** hoặc **min-heap size k**
+ Quickselect: partition như Quick Sort, chỉ đệ quy một phía
+ Index mục tiêu: `n - k` (sort ascending) hoặc pivot logic descending

## 4. Hướng tiếp cận từng bước

**Quickselect:**

1. `target = len(nums) - k` (vị trí trong mảng sort ascending)
2. `partition(lo, hi)`: pivot (vd phần tử cuối), Lomuto → trả index `p`
3. Nếu `p == target` → `nums[p]`; `p < target` → tìm bên phải; ngược lại trái

**Heap:** Min-heap k phần tử; khi size > k pop nhỏ nhất → top là kth largest.

## 5. Code Python

```python
import random


def findKthLargest(nums: list[int], k: int) -> int:
    target = len(nums) - k

    def partition(lo: int, hi: int) -> int:
        pivot_idx = random.randint(lo, hi)
        nums[pivot_idx], nums[hi] = nums[hi], nums[pivot_idx]
        pivot = nums[hi]
        i = lo
        for j in range(lo, hi):
            if nums[j] <= pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[hi] = nums[hi], nums[i]
        return i

    def select(lo: int, hi: int) -> int:
        p = partition(lo, hi)
        if p == target:
            return nums[p]
        if p < target:
            return select(p + 1, hi)
        return select(lo, p - 1)

    return select(0, len(nums) - 1)
```

## 6. Trace nums=[3,2,1,5,6,4], k=2 → target index 4 (giá trị 5)

Sau vài partition (tùy pivot), phần tử tại index `n-k=4` trong mảng sorted ascending là **5**.

Heap trace: push 3,2,1,5,6,4 — giữ heap min size 2 → top 5 sau khi ổn định.

## 7. Phân tích độ phức tạp

+ **Quickselect average O(n)**: Tương tự quick sort nhưng một nhánh
+ **Worst O(n²)**: Pivot xấu — random pivot giảm xác suất
+ **Heap O(n log k)**: k nhỏ thì heap gọn; k ≈ n thì quickselect thường hơn

Sort toàn mảng O(n log n) đơn giản nhưng chậm hơn khi chỉ cần một thứ hạng.
