Trên đường đua, rùa và thỏ cùng xuất phát — nhưng thỏ chạy **gấp đôi** bước mỗi lần. Nếu đường là vòng tròn (cycle), dù rùa chậm, thỏ **sẽ đuổi kịp** rùa ở đâu đó trên vòng. Không cần đếm toàn bộ đường hai lần. Đó là trực giác **Fast & Slow pointer** cùng hướng: hai con trỏ cùng chiều, tốc độ khác nhau — O(n) time, O(1) space trên linked list.

## 1. Intuition

+ **Fast / Slow trên linked list**: Slow +1 node, fast +2 node mỗi bước. Không cycle → fast tới `null`. Có cycle → fast “lặp vòng”, chắc chắn gặp slow.
+ **Read / Write trên array**: `read` quét toàn bộ, `write` chỉ ghi phần “giữ lại” — xóa trùng in-place, đẩy số 0 về cuối mà không tạo mảng mới.
+ **Tìm giữa list**: Fast đi 2 bước, slow 1 bước — khi fast hết, slow ở giữa (một pass).

Cùng hướng khác **opposite** (bài trước): không khép từ hai đầu mà **cùng quét** với vai trò khác nhau.

## 2. Cách hoạt động — từng bước

**Floyd cycle detection** trên list: `1 → 2 → 3 → 4 → 2` (cycle tại node 2).

| Bước | slow | fast | Gặp? |
|------|------|------|------|
| 0 | 1 | 1 | |
| 1 | 2 | 3 | |
| 2 | 3 | 2 (wrap) | |
| 3 | 4 | 4 | **slow == fast** → có cycle |

**Remove duplicates sorted array** `nums = [1,1,2,2,3]`:

+ `write = 1` (phần đã “unique” kết thúc tại index 0)
+ `read` từ 1: nếu `nums[read] != nums[write-1]` → `nums[write] = nums[read]`, `write++`
+ Kết quả độ dài unique = `write`, phần đầu `[1,2,3,...]`

## 3. Tại sao giải thuật này đúng?

**Cycle (Floyd):** Gọi μ = khoảng cách từ head tới cycle, λ = độ dài cycle. Sau khi slow vào cycle, fast đã trong cycle; khoảng cách giữa chúng trên vòng giảm 1 mỗi bước (fast +2, slow +1) → sau ≤ λ bước fast đuổi kịp slow.

**Read/Write invariant:** `nums[0..write-1]` luôn là dãy unique đã xử lý; `read` chỉ mở rộng cửa sổ quan sát. Mảng sorted → duplicate liên tiếp → chỉ cần so với phần tử unique cuối.

## 4. Phân tích độ phức tạp

+ **Cycle / middle**: O(n) — mỗi node visited hữu hạn lần; không cần HashSet O(n) space để đánh dấu visited.
+ **In-place filter (283, 26)**: O(n) time, O(1) extra space — `write` chỉ reorder trong mảng gốc.
+ So với copy sang mảng mới: cùng O(n) time nhưng O(n) space thêm.

## Common Mistakes: Fast & Slow Pointer

- **Fast null check**: Luôn `while fast and fast.next` trước nhảy 2 bước — tránh `AttributeError` / null pointer.
- **Middle chẵn/lẻ**: Đề #876 lấy node thứ hai khi chẵn — code `while fast and fast.next` (không `fast.next.next` only).
- **Cycle trên array index**: Floyd chuẩn cho **linked list**; array “cycle” thường là graph/index khác (Floyd trên index) — đừng nhầm pattern.
- **Move Zeroes**: Quên gán `nums[write] = nums[read]` trước khi tăng write; hoặc quên fill 0 phần đuôi.
- **Remove duplicates**: `write` bắt đầu 1 (không 0) vì phần tử đầu luôn unique trên mảng sorted.
