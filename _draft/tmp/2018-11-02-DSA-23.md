Chào các bạn, bạn vào mê cung, gặp ngã ba: rẽ trái, thử — cụt đường, **quay lại**, thử phải. **Backtracking** chính là chiến lược đó: thử một lựa chọn, nếu không được thì **undo** và thử lựa chọn khác.

## 1. Intuition

Giải Sudoku: bạn điền số vào ô trống. Nếu sau vài bước phát hiện xung đột, bạn **xóa số vừa điền** và thử số khác — không bắt đầu lại từ đầu bảng.

Backtracking = **DFS có undo**: explore một nhánh của không gian lời giải, cắt sớm nhánh vô vọng (**pruning**).

## 2. Cách hoạt động — từng bước

**Template chung:**

```
def backtrack(state):
    if is_complete(state):
        record solution
        return
    for choice in choices:
        if is_valid(choice):
            make(choice)          # thử
            backtrack(state)      # đi sâu
            undo(choice)          # backtrack — quan trọng!
```

**Maze / path finding:**

1. Thử move một trong 4 hướng
2. Mark cell **visited**
3. Nếu đến goal → ghi nhận
4. Nếu dead end → **unmark** (undo), quay lại bước trước
5. **Prune**: bỏ nhánh vi phạm constraint ngay (vd: ra ngoài biên, đã visit)

**Trace tìm đường trong maze 3×3:** Bắt đầu (0,0), thử Down → Right → Right. Gặp tường → undo Right cuối → thử Down → … cho đến goal hoặc hết lựa chọn.

## 3. Tại sao giải thuật này đúng?

Backtracking là **exhaustive search có cấu trúc** trên cây quyết định:

+ Mỗi **node** = một trạng thái partial solution
+ Mỗi **edge** = một choice
+ **Leaf** hoàn chỉnh = một solution hợp lệ

**Invariant:** Sau mỗi `undo`, state trở về đúng trạng thái trước khi `make` — nhánh khác được explore từ cùng điểm xuất phát.

Pruning không bỏ sót solution đúng vì chỉ cắt nhánh **đã chứng minh không thể** dẫn tới nghiệm (constraint violation).

## 4. Phân tích độ phức tạp

| Bài | Worst case | Sau pruning |
|-----|------------|-------------|
| Permutations n phần tử | O(n!) | — |
| Subsets 2ⁿ | O(n × 2ⁿ) | Skip duplicate |
| N-Queens | Exponential | Prune conflict sớm |
| Maze m×n | O(4^(m×n)) | Visited set giảm mạnh |

**Space:** O(depth) call stack + O(state) cho visited/path.

## Common Mistakes: Backtracking

- **Quên undo**: Phải revert state sau mỗi recursive call — nếu không, nhánh sau bị "ô nhiễm".
- **Không prune sớm**: Check invalid ngay khi make choice, không explore hết rồi mới check.
- **Duplicate solutions**: Combinations dùng `start index`; có duplicate sort + skip cùng level.
- **Copy state mỗi lần**: Dùng append/pop in-place thay vì copy list — tiết kiệm memory.
