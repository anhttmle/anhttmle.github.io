*Bài này áp dụng **Recursion** từ [DSA Understanding – Part 21](/dsafundamental/2018/10/19/DSA-21.html).*

## 1. Đề bài đầy đủ

Cho mảng ký tự `s`. **Đảo ngược** chuỗi **in-place** với O(1) extra memory (modifying input array).

## 2. Ví dụ minh hoạ

| Input | Output |
|-------|--------|
| ["h","e","l","l","o"] | ["o","l","l","e","h"] |
| ["H","a","n","n","a","h"] | ["h","a","n","n","a","H"] |

## 3. Nhận diện pattern

+ Đảo chuỗi = swap phần tử đầu và cuối, thu hẹp vùng giữa
+ **Two Pointer** O(n) iterative — đơn giản nhất
+ **Recursion**: swap `s[left], s[right]` → gọi `reverse(left+1, right-1)` — base `left >= right`

## 4. Hướng tiếp cận từng bước

**Two Pointer:**

1. `left = 0`, `right = len(s) - 1`
2. While `left < right`: swap `s[left]` và `s[right]`, tăng left, giảm right

**Recursion:**

1. Base: `left >= right` → return
2. Swap `s[left], s[right]`
3. Gọi `helper(left + 1, right - 1)`

## 5. Code Python

Two pointer:

```python
def reverseString(s: list[str]) -> None:
    left, right = 0, len(s) - 1

    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
```

Recursion:

```python
def reverseString(s: list[str]) -> None:
    def helper(left: int, right: int) -> None:
        if left >= right:
            return
        s[left], s[right] = s[right], s[left]
        helper(left + 1, right - 1)

    helper(0, len(s) - 1)
```

## 6. Trace through s = ["h","e","l","l","o"]

| left | right | Swap | s sau swap |
|------|-------|------|------------|
| 0 | 4 | h↔o | o,e,l,l,h |
| 1 | 3 | e↔l | o,l,l,e,h |
| 2 | 2 | stop | o,l,l,e,h ✓ |

## 7. Phân tích độ phức tạp

+ **Time O(n)**: Mỗi cặp swap một lần, n/2 lần
+ **Space O(1)** iterative; **O(n)** stack nếu recursion (n/2 frames)
