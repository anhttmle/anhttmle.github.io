*Bài này áp dụng **Fixed Sliding Window** từ [DSA Understanding – Part 14](/dsafundamental/2018/08/31/DSA-14.html).*

## 1. Đề bài đầy đủ

Cho mảng số nguyên `nums` và số nguyên `k`. Trả về **trung bình lớn nhất** của bất kỳ subarray nào có độ dài **k**.

## 2. Ví dụ minh hoạ

| nums | k | Output | Giải thích |
|------|---|--------|------------|
| [1,12,-5,-6,50,3] | 4 | 12.75 | [12,-5,-6,50] sum=51 |
| [5] | 1 | 5.0 | |

## 3. Nhận diện pattern

+ Subarray **độ dài cố định k** → fixed window
+ Max average ⟺ max **sum** (chia k một lần cuối)
+ Update O(1): `sum += nums[i] - nums[i-k]`

## 4. Hướng tiếp cận từng bước

1. Tính `window_sum` cho `nums[0:k-1]`
2. `max_sum = window_sum`
3. `i` từ `k` đến `n-1`: cập nhật sum, `max_sum = max(max_sum, window_sum)`
4. Trả `max_sum / k`

## 5. Code Python

```python
def findMaxAverage(nums: list[int], k: int) -> float:
    window_sum = sum(nums[:k])
    max_sum = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, window_sum)
    return max_sum / k
```

## 6. Trace nums=[1,12,-5,-6,50,3], k=4

| i | Window | sum | max_sum |
|---|--------|-----|---------|
| init | [1,12,-5,-6] | 2 | 2 |
| 4 | [12,-5,-6,50] | 51 | 51 |
| 5 | [-5,-6,50,3] | 42 | 51 |

Output: 51/4 = **12.75**

## 7. Phân tích độ phức tạp

+ **Time O(n)**
+ **Space O(1)**
