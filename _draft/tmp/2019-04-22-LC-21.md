*Bài này áp dụng **Merge hai dãy đã sort** từ [DSA Understanding – Part 11](/dsafundamental/2018/08/10/DSA-11.html).*

## 1. Đề bài đầy đủ

Cho hai linked list `list1`, `list2` đầu đã **sort tăng dần**. Trộn thành **một** list sorted, trả về `head` của list mới.

## 2. Ví dụ minh hoạ

| list1 | list2 | Output |
|-------|-------|--------|
| 1→2→4 | 1→3→4 | 1→1→2→3→4→4 |
| [] | 0 | 0 |
| 2 | [] | 2 |

## 3. Nhận diện pattern

+ Hai sequence sorted → hai pointer, chọn min (giống merge phase Merge Sort)
+ Dummy head giữ tail — O(1) extra pointer
+ Còn dư một list → nối phần còn lại

## 4. Hướng tiếp cận từng bước

1. `dummy = ListNode(0)`, `tail = dummy`
2. `while list1 and list2`:
   - Nếu `list1.val <= list2.val`: nối list1, list1 = list1.next
   - Ngược lại: nối list2
   - `tail = tail.next`
3. `tail.next = list1 or list2`
4. `return dummy.next`

## 5. Code Python

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


def mergeTwoLists(list1, list2):
    dummy = ListNode(0)
    tail = dummy

    while list1 and list2:
        if list1.val <= list2.val:
            tail.next = list1
            list1 = list1.next
        else:
            tail.next = list2
            list2 = list2.next
        tail = tail.next

    tail.next = list1 if list1 else list2
    return dummy.next
```

## 6. Trace list1=1→2→4, list2=1→3→4

| list1 | list2 | tail chain (sau dummy) |
|-------|-------|------------------------|
| 1 | 1 | 1 (từ list1) |
| 2 | 1 | 1→1 |
| 2 | 3 | 1→1→2 |
| 4 | 3 | 1→1→2→3 |
| 4 | 4 | ...→4 |
| nối 4 còn | | 1→1→2→3→4→4 |

## 7. Phân tích độ phức tạp

+ **Time O(n + m)**: Mỗi node visited một lần
+ **Space O(1)**: Chỉ pointer (reuse node, không tạo n node mới nếu không yêu cầu)
