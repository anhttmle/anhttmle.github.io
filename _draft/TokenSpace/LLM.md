# Training an LLM:
- **Data Collection & Preparation**: Collect, clean, deduplicate, filter, tokenize
- **Pre-training**: next token prediction, knowledge accumulation in parametric memory.
- **Supervised Fine-Tuning** (SFT): Learn to follow instructions and produce useful responses
- **Preference Alignment** (such as RLHF): Learn which responses humans or reward models prefer 
- **Capability-Specific Post-Training**: coding, tool use, domain adaptation
