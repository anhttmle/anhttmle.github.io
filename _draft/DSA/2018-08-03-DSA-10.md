Bạn có bảng điểm theo **hàng và cột** (lớp × môn). Cô hỏi liên tục: “Tổng điểm khối từ hàng 2–5, cột 1–4?” Cộng từng ô mỗi lần rất chậm. Giải pháp: dựng bảng **tích lũy 2D** một lần — mỗi ô lưu tổng toàn bộ hình chữ nhật từ góc trên-trái đến đó — rồi mỗi câu hỏi chỉ cần **bốn góc** và cộng/trừ (inclusion-exclusion).

## 1. Intuition

+ **Ma trận / lưới**: Game, heatmap, ảnh grayscale — vùng hình chữ nhật xuất hiện liên tục.
+ **Mở rộng 1D**: 1D là “dải liên tiếp”; 2D là “khối chữ nhật” — công thức tương tự nhưng trừ phần thừa hai lần rồi cộng góc chung.
+ **Range Sum Query 2D (#304)**: Class nhận matrix, trả lời sum vùng (r1,c1)–(r2,c2) trong O(1).

## 2. Cách hoạt động — từng bước

Ma trận `matrix` kích thước m×n. Prefix `P` kích thước **(m+1)×(n+1)**, hàng 0 và cột 0 toàn **0**.

**Build** (1-indexed trên P, ô matrix tại i-1, j-1):

\\[
P[i][j] = matrix[i-1][j-1] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]
\\]

**Ví dụ** matrix 2×2: `[[1,2],[3,4]]` → P[1][1]=1, P[1][2]=3, P[2][1]=4, P[2][2]=10.

**Query** vùng top-left (r1,c1) bottom-right (r2,c2) **0-index trên matrix**:

\\[
\text{sum} = P[r2+1][c2+1] - P[r1][c2+1] - P[r2+1][c1] + P[r1][c1]
\\]

Trace vùng (0,0)–(1,1) trên ví dụ trên: `10 - 0 - 0 + 0 = 10` (= 1+2+3+4).

## 3. Tại sao giải thuật này đúng?

**Invariant:** `P[i][j]` = tổng mọi ô trong hình chữ nhật matrix[0..i-2][0..j-2] (theo convention 1-index P).

Khi build, ô mới = giá trị matrix + hai “tấm” prefix kề − góc bị cộng hai lần (inclusion-exclusion).

Khi query, lấy tấm lớn `P[r2+1][c2+1]`, trừ hai dải thừa, cộng lại góc `P[r1][c1]` bị trừ thừa — đúng tổng khối nội bộ.

## 4. Phân tích độ phức tạp

+ **Build:** O(m × n) — mỗi ô P tính một lần từ ba neighbor + matrix.
+ **Query:** O(1) — bốn phép đọc P.
+ **Không dùng prefix:** Mỗi query O(m × n) cộng vùng → q query là O(q × m × n).
+ **Space:** O(m × n) cho bảng P (thường chấp nhận được vì cùng order với input).

1D Kadane O(n) cho **maximum subarray** là bài khác; 2D prefix phục vụ **sum cố định vùng**, không thay Kadane cho max sum 1D.

## Common Mistakes: 2D Prefix Sum

- **P 1-indexed**: Size (m+1)×(n+1), hàng/cột 0 = 0 — nhầm với matrix 0-index gây lệch công thức.
- **Dấu inclusion-exclusion**: Trừ `P[r1][c2+1]` và `P[r2+1][c1]`, **cộng** `P[r1][c1]` — đổi dấu một góc là sai toàn vùng.
- **Nhầm tọa độ**: Đề cho row1,col1,row2,col2 inclusive — map đúng vào `P[r2+1][c2+1]` không phải `P[r2][c2]`.
- **Nhầm với integral image / DP khác**: Cùng ý tưởng cộng dồn nhưng convention index khác giữa tài liệu — thống nhất một convention trong code.
- **Matrix rỗng / một hàng**: Vẫn cần lớp P đủ chiều +1.
