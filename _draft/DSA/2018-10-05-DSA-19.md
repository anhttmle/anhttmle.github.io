Chào các bạn, từ điển không chỉ sort trên giấy — **Binary Search Tree (BST)** là cây mà mọi node **trái nhỏ hơn**, **phải lớn hơn** node đó. Tìm kiếm giống binary search nhưng trên cấu trúc cây: mỗi bước loại một nửa **theo quan hệ lớn/nhỏ**.

## 1. Intuition

Hộp đựng thẻ tên: mở hộp giữa, tên nhỏ hơn sang ngăn trái, lớn hơn sang phải — không cần duyệt hết. BST làm tương tự với `val`.

**In-order traversal** (left → root → right) in ra **thứ tự tăng dần** — property quan trọng để verify và giải bài.

## 2. Cách hoạt động — từng bước

**Search:**

1. Bắt đầu `cur = root`
2. `val == cur.val` → found; nhỏ hơn → trái; lớn hơn → phải
3. `cur == null` → không có

**Insert:** Đi như search đến `null`, gắn node mới.

**Remove (3 case):**

1. Leaf → xóa pointer
2. Một con → thay bằng con đó
3. Hai con → thay value bằng **inorder successor** (min cây phải), rồi xóa successor

## 3. Tại sao giải thuật này đúng?

**BST property** được giữ khi insert đúng chỗ leaf theo so sánh — mọi node trái vẫn < parent < phải.

**Delete hai con:** Successor là min bên phải → lớn hơn mọi node trái, nhỏ hơn mọi phần còn lại bên phải → thay value không phá property, xóa successor chỉ rơi vào case 0–1 con.

## 4. Phân tích độ phức tạp

+ **Search / Insert / Delete:** O(h) với h = height
+ **Balanced BST:** h = O(log n) → O(log n)
+ **Skewed (insert sorted):** h = n → O(n) — linked list

## Common Mistakes: BST

- **Duplicate:** Quy ước ≤ trái hoặc ≥ phải — thống nhất với đề bài.
- **Sorted input:** Cây lệch một bên — production dùng AVL/Red-Black.
- **Delete hai con:** Copy value successor rồi xóa node successor, không chỉ swap pointer lung tung.
- **Nhầm với binary tree:** Property sort chỉ có trên BST.
